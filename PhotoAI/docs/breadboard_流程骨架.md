# PhotoAI Hub 流程骨架（breadboard）

> 目的：**在你写代码/画界面之前，先确认"这系统到底该干什么"**。
> 每行只回答三件事：在哪个**位置**、有什么**可操作物**、点了**去哪**。

## 全局连接图

```
[小程序]
 登录页 ──成功──> 作品列表 ──点卡片──> 作品详情 ──点作者──> 作者页
                      │                   │  │
                      │                   │  └──画廊(大图)
                      │                   ├──点赞  ⚠️
                      │                   └──评论  ⚠️
                      ├──分类筛选 ❌
                      └──搜索框 ──关键词──> 列表(过滤) ✅
                                 └─AI检索──> ❌ 无

 我的 ──> 发布作品 ❌ ──> [上传+填标题/描述/分类] ──> 待审核 ❌

[后台 layuimini]                        [数据库]
 登录页 ✅ ──> 后台首页 ✅ ──> 作品管理 ✅(只读列表)
                        └──> 审核页 ❌ ──通过──> wstatus=展示 ✅
                                       └─驳回──> wstatus=?  ❌（无"驳回"态）
                        └──> 用户管理 ✅ ──> 用户编辑 ✅
```

## 流程 1 · 登录（微信）

| 位置 | 可操作物 | 连到哪 | 现状 |
|---|---|---|---|
| 小程序登录页 `pages/login` | **"微信一键登录"按钮** | `wx.login()` → code → `POST /auth/wxlogin` → openid → JWT | ❌ 接口不存在；现为手机号+密码 |
| 同上 | 首次登录自动建号 | 落 `user`（`role=普通用户`、`status=正常`） | ❌ `user` 表**无 openid 字段** |
| **游客**（未登录） | 直接进画廊 / 作品列表 / 详情 | 只读接口放行 | ⚠️ 拦截器现在除登录页全拦 |
| 触发登录的操作 | 点赞 / 评论 / 收藏 / 私信 / 发布 / 我的 | 未登录 → 引导到登录页 | ⚠️ 需前端拦截 + 后端 401 双保险 |
| 后台登录页 `/login/page` | 管理员账号、密码 | → `/page/admin/index` | ✅（管理员仍走账密，不走微信） |
| 全局 | — | 请求自动带 JWT；过期 → 401 | ✅ interceptor |

## 流程 6 · 账号体系（微信登录后，密码能力整体删除）

| 位置 | 可操作物 | 连到哪 | 现状 |
|---|---|---|---|
| 小程序「我的」→ 资料编辑 `pages/userEdit` | 昵称、头像、简介 | `PUT /user/update` | ⚠️ 有页面，但表单里**还带 role / vote 字段** → 必须删 |
| 同上 | ~~密码~~ | — | **删除**（微信登录无密码；改密码/找回密码一并移出） |
| 后台 用户管理 | 禁用 / 启用 / 批量删 | `PUT /user/disable/{uid}`、`/enable/{uid}`、`DELETE /user/batch` | ⚠️ 有，但**不校验调用者是否管理员** |
| 系统配置 | AppID / AppSecret、JWT 密钥 | 环境变量 | ⚠️ `application.yml` 有默认 JWT 兜底密钥，必须去掉 |

> **这条线比看起来严重**：`PUT /user/update` 收整个 `User` 实体 + 前端表单里有 `role`/`vote` → **普通用户可自提管理员、自刷积分**。这已经不是"没改密码"，是权限模型没建立。

## 从骨架看出的 5 个断层

| # | 断层 | 影响 |
|:-:|---|---|
| 1 | **发布 → 审核 整条链不存在**（无入口、无页面、无接口、无状态） | "社区"最核心的闭环是空的，演示只能展示别人造的数据 |
| 2 | 互动三件（评论/点赞/分类）**表全有、接口全无** | 论文第 5 章没有可截图的互动功能 |
| 3 | `wstatus` 只有"展示/隐藏"，**没有审核态** | 内容审核无法落地（不是补枚举，是补状态机） |
| 4 | 后台只有"看"，没有"审" | 管理员角色形同虚设，权限矩阵也画不出来 |
| 5 | 热门榜视图存在但**从未被调用** | Redis 缓存没有可缓存的对象（F-09 要先有读路径） |
