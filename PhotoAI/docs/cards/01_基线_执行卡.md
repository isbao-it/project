## 5. 实现要点

- **错误码**（见架构 §6）：`ok / invalid_request / unauthorized / forbidden / not_found / conflict / too_many_requests / payload_too_large / internal_error`；HTTP 与 code 同时给对，**不许**用领域状态码冒充请求不合法
- **异常处理**：`@RestControllerAdvice` 兜 `MethodArgumentNotValidException`、`MissingServletRequestParameterException`、`HttpRequestMethodNotSupportedException`、`Exception`；**响应体不含堆栈、不含 SQL、不含手机号/openid/token**
- **鉴权**：`AuthInterceptor` 里 `uri.contains(...)` 收敛为一张规则表（`Set<String> ADMIN_PATH_PREFIXES` 或配置项），未命中放行；命中且 `role != 管理员` → 403 JSON
- **`/user/update` 白名单**：普通用户只允许 `uname / avatar / pnum`（pnum 仍需唯一性校验）；`role / status / vote / pwd / openid / uid` **静默忽略**（不报错、不落库）；管理员可改 role/status/vote。改密走独立接口（本卡不做，留 TODO 指向卡 03）
- **配置外置**：`application.yml` → `url: jdbc:mysql://${DB_HOST:localhost}:${DB_PORT:3306}/${DB_NAME:db_pg}...`、`username: ${DB_USER:root}`、`password: ${DB_PASSWORD}`、JWT → `${JWT_SECRET}`；**无默认值**的项必须由 `run-local.ps1` 设好；`.env.example` 写占位，`.env` 进 `.gitignore`
- **日志**：新代码用 SLF4J；异常处理里 `log.error("... uid={}", uid, e)`，**禁**打印 token/口令
- **前端对齐**：`grep -rn "code *=== *200"` 必须为 0 处残留（Thymeleaf 15 处 + 小程序 2 处）；小程序的 `request.js` 是**全局唯一入口**，必须先改它；守卫脚本 `assert-frontend-code.sh` 输出 `PASS/FAIL`，残留一处即 FAIL
