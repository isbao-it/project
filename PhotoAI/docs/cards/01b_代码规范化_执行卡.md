## 2. 逐项清单

### 2.1 类重命名（9 个，逻辑零改动）

- 同步改：类声明、构造器名、同类内部 `LoggerFactory.getLogger(X.class)`、测试中若 import 了这些类则一并改（测试断言不许改）

### 2.2 日志

- `userController` 中 `System.out.println(...)` → `log.info(...)`（参数化，禁拼接）
- `PgApplication` 中 `System.out.println` → `log.info`
- `printStackTrace()` → `log.error("...", e)`
- 新增 `private static final Logger log = LoggerFactory.getLogger(X.class);`
- **禁止**在日志里打印手机号、pwd、openid、token

### 2.3 注入方式

- 11 处 `@Autowired private Xxx yyy;` → 构造器注入：
```java
private final XxxService xxxService;

public FooController(XxxService xxxService) {
    this.xxxService = xxxService;
}
```
- 循环依赖若出现（构造器注入无法解），**停下来报告**，不许改回字段注入

### 2.4 错误码收敛（35 处手工 `AjaxResult.error(int, String)`）

- 改为 `throw new BizException(ErrorCode.XXX, "中文说明");`，由 `GlobalExceptionHandler` 出信封
- **映射规则**（不得自创）：
  - 未登录/令牌无效 → `UNAUTHORIZED`（401）
  - 无权限 → `FORBIDDEN`（403）
  - 参数非法/缺字段 → `INVALID_REQUEST`（400）
  - 资源不存在 → `NOT_FOUND`（404）
  - 唯一键冲突/重复 → `CONFLICT`（409）
  - 其余内部错误 → `INTERNAL_ERROR`（500），**不许把 SQL/异常原文回给前端**
- **响应结构不变**：原本 `AjaxResult.success(...)` 的成功路径**一行不动**；只有错误分支改抛异常
- ⚠️ 前端已按 `code === 'ok'` 判断成功，改完必须保证成功响应仍是 `code:"ok"`
