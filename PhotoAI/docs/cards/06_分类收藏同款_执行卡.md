## 数据、接口和算法约束

- 分类只读 `pclist(pcid,pcname,cds,sort,ct)`，按 sort 升序、pcid 升序返回所有字典项；零作品分类也返回 count=0。以 `pwork.pcid=pclist.pcid AND wstatus='展示'` 聚合，响应每项恰为 pcid:string、pcname:string、count:非负integer。不输出 cds/sort/ct，不读旧 pcatogory.pc_count，不自动迁移历史分类或植入字典数据。sort 次序来自 V002 列注释，pcid 作为同 sort 的稳定次序是本卡补充验收口径。
- 收藏表为 `favorite(fid,uid,pid,ct)`，复用 `uk_uid_pid(uid,pid)`；uid 只来自已验证身份。重复添加/取消都 HTTP200/code=ok；响应分别恰为 `{favorited:true,count:N}`、`{favorited:false,count:N}`。count 是该作品所有用户的收藏记录数，不是本人条数、likep或本页长度。
- 并发相同 uid/pid 添加只留一行，每个请求都成功；并发取消最多删一次，每个请求都成功。唯一键竞争只在本业务内收敛，不吞未知 SQL 错误，不增加全局 DuplicateKeyException→409。不能给 pwork 新增或维护收藏计数字段。
- 作品不存在或状态为待审核/隐藏/已驳回：添加、取消均404 not_found，作者与管理员也不能绕过；已有收藏记录仍不能取消。本人列表只返回展示作品，以 favorite.ct DESC、favorite.fid ASC 排序，list与total使用完全相同的本人及可见性过滤；历史非展示收藏保留，不以读请求清理记录。
- 分页 page 默认1且≥1，size默认10且1–50；格式不符或越界400 invalid_request；超页成功返回空 list 与过滤后的真实 total。不把 pageNum/pageSize 作为别名。
- 同款源图必须存在且展示；否则404 not_found。候选只选展示、同 `pwork.pcid`、排除源 pid。分类为空不猜测映射，本卡以源 pcid=NULL 返回空、候选 pcid=NULL 不匹配验收。
- 光圈必须满足 `ABS(LOG2(a1)-LOG2(a2))<=1`；焦距必须满足 `ABS(f2-f1)/f1<=0.20`，分母是源焦距 f1。**两项同时成立**；不得换成光圈数值相减、只判断一项或用候选焦距作分母。边界均包含；零/负数先排除，不执行无定义的 LOG 或除法。
- 源无 work_exif 行、focal/aperture 任一为 NULL/0/负数，成功返回 `{list:[]}`；候选缺项或非正数直接排除。shutter/iso/lens/camera 为空不影响必要双参数匹配。无结果不热门补位、不用向量检索。
- 同款按 likep DESC、pid ASC，limit 默认6、范围1–20，非法值400，不静默截断21为20。只返回 `{list:[完整Work]}`，无 total、score、exif、stripped 或 reason。
- Work 恰含 pid、uid、wtitle、wdesc、vurl、viewcount、votecount、wstatus、cwtime、likep、uname、avatar、pcname、realLikeCount 十四键；空值键保留。count/total/全部作品计数用 Long，JSON非负integer；ID始终string，pid为1–36位字母数字/_/-。时间按 Asia/Shanghai 显式投影为带秒与 +08:00 的 ISO8601，不改全局 Jackson。
- 所有响应顶层恰为 code:string、msg:安全中文string、data；错误 data=null。业务错误抛既有 BizException/ErrorCode，由现有全局处理器输出真实HTTP，不能用200包错误码。读分类/收藏列表/同款不增加浏览、不改作品、分类、EXIF或关系记录。
