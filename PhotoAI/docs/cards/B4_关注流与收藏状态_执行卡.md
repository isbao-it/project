# B4 关注流与收藏状态执行卡

## 1. 目标

两件事，都服务于「关注」和「收藏」在界面上的真实可用：

1. **关注流**：新增 `GET /pwork/following`，返回「我关注的人发布的展示作品」分页列表（契约 #11，归 FeedController 独占）；
2. **收藏可见**：作品详情返回 `favoriteCount`（收藏总数）与 `favorited`（当前登录用户是否已收藏），让详情页收藏按钮和数字**一进页面就是真值**，不必等用户点一下才出现。

依据：`docs/接口冻结_v1.md` §1.3 #11、§1.6 #26/#27、§1.7 与 §六 卡07 文件归属表。

## 2. 现状（已核实）

- `follow` 表：`fid`(PK)、`uid`(关注者)、`tuid`(被关注者)、`ct`；当前 26 行。
- `favorite` 表：`fid`(PK)、`uid`、`pid`、`ct`；当前 45 行。

- `WorkQueryServiceImpl.detail(pid, viewerUid)` 已经接收 `viewerUid`（B1 加的），可直接复用判断是否已收藏。

## 3. 后端改动

### 3.1 新建关注流（契约 #11）

新建文件（**不要改 PworkController**）：

- `Backend/src/main/java/com/pg/controller/FeedController.java`
- `Backend/src/main/java/com/pg/service/FeedService.java`
- `Backend/src/main/java/com/pg/service/impl/FeedServiceImpl.java`
- `Backend/src/main/java/com/pg/mapper/FeedMapper.java`
- `Backend/src/main/resources/mapper/FeedMapper.xml`

**接口**

```
GET /pwork/following?page=1&size=10
权限：登录（@RequestAttribute String uid）
响应：{ list: Work[], total: N }
```

**SQL 语义**

```sql
SELECT <Work 列，复用 WorkQueryMapper 的 Columns 或等价列清单>
FROM follow f
JOIN pwork p ON p.uid = f.tuid
LEFT JOIN user u ON u.uid = p.uid
LEFT JOIN pclist c ON c.pcid = p.pcid
WHERE f.uid = #{uid} AND p.wstatus = '展示'
ORDER BY p.cwtime DESC, p.pid ASC
LIMIT #{size} OFFSET #{offset}
```

- `total` 用同一 `WHERE` 条件 `COUNT(*)`，**不含分页**；
- 只返回 `wstatus='展示'`；
- 必须带 `p.pid ASC` 兜底，保证分页稳定；
- **自关注**（关注自己）的作品是否出现由数据决定，不额外过滤。

**参数校验**（沿用项目既有规则）

- `page` 默认 1、必须 ≥1；`size` 默认 10、范围 1–50；非整数或越界 → 400 `invalid_request`；
- 未登录 → 401 `unauthorized`；
- 页码超出范围为成功空页（`list:[]`、`total` 正常）。

**必须复用 `WorkQueryServiceImpl.project()` 的字段投影**，不要在 FeedServiceImpl 里另写一套字段清单——把 `workQueryService` 注入进来或用同款 `FIELDS` 常量均可，但**返回字段必须与 `/pwork/list` 完全一致**。

### 3.2 详情补收藏字段

`WorkQueryMapper.xml`：

1. `<sql id="Columns">` 末尾追加一个子查询列：
   ```sql
   (SELECT COUNT(*) FROM favorite fa WHERE fa.pid = p.pid) AS favoriteCount
   ```
2. `resultMap id="Work"` 追加：
   ```xml
   <result column="favoriteCount" property="favoriteCount" javaType="java.lang.Long"/>
   ```

`WorkQueryServiceImpl.java`：

3. `FIELDS` 末尾追加 `"favoriteCount"`；
4. `COUNTERS` 末尾追加 `"favoriteCount"`（保证返回 Long 而不是 null）；
5. `detail(String pid, String viewerUid)` 里，在组装 `work` 之后追加登录态判断：

```java
// 收藏状态只对已登录请求者有意义；匿名一律 false，不泄漏他人状态。
boolean favorited = false;
if (viewerUid != null) {
    favorited = favoriteMapper.exists(viewerUid, pid);
}
work.put("favorited", favorited);
```

需要一个查询方法：在 `FavoriteMapper`（已存在）加

```java
/** 判断某个用户是否收藏了某作品。 */
boolean exists(@Param("uid") String uid, @Param("pid") String pid);
```

XML：

```xml
<select id="exists" resultType="boolean">
    SELECT EXISTS(SELECT 1 FROM favorite WHERE uid=#{uid} AND pid=#{pid})
</select>
```

**注意**：`favorited` 只加在**详情**响应的 `work` 对象里，不加进 `FIELDS`（列表接口不需要，避免每条都查一次）。
