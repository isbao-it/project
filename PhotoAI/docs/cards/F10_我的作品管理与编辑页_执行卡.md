# F10 我的作品管理与编辑页执行卡

## 1. 目标

三件事：

1. 「我的」页的作品 tab 去掉「我的作品 共 N 件」标题行和五个状态筛选胶囊，直接平铺全部作品；
2. 作品详情页区分**作者视角**——作者自己打开时不显示作者头像/昵称/关注按钮，改为显示**作品状态标签** + **「更多」管理入口**；
3. 新建「编辑作品」页，支持改标题、描述、分类后提交（PUT 会重新进入待审核）。

依据：`docs/接口冻结_v1.md` §1.3 #9（`PUT /pwork/{pid}`）、#10（`DELETE /pwork/{pid}`）、#6（详情）、#25（分类列表）。

## 2. 接口事实（已核实）

| 能力 | 接口 | 说明 |
|---|---|---|
| 详情 | `GET /pwork/{pid}` | 返回 `work`（含 `uid`/`wstatus`/`wtitle`/`wdesc`/`vurl`/`pcid`）、`exif`、`author` |
| 分类 | `GET /category/list` | `{list}`，每项 `pcid/pcname/count` |
| 保存 | `PUT /pwork/{pid}` | body **四字段全量覆盖**：`title`（非空白 ≤100）、`desc`（≤255，可为空串）、`imageUrl`（非空白 ≤255）、`categoryId`；成功后作品状态回到**待审核** |
| 删除 | `DELETE /pwork/{pid}` | 作者可删；成功返回 `null` |

**本轮编辑页不支持更换图片**：`imageUrl` 沿用详情返回的 `work.vurl` 原值提交。换图需另开卡（涉及上传与 EXIF 重算）。

## 3. 「我的」页简化（`pages/mine/*`）

- 删除内容区顶部的「我的作品 共 N 件」标题行（整块移除，不是隐藏）。
- 删除五个状态筛选胶囊（全部/待审核/展示/隐藏/已驳回）整行。
- 作品列表直接平铺全部作品（`loadWorks` 不再传 `status`）。
- 卡片保留：缩略图、标题、**状态标签**、驳回原因（有则显示）。
- `onStatusChange` 与 `status` 数据可保留但不再被任何 UI 触发；`loadWorks` 的请求参数与分页逻辑**不得改动**（只是不再传 status）。
- 「收藏 / 喜欢 / 设置」三个 tab 的行为不变。

## 4. 详情页作者视角（`pages/workDetail/*`）

在 `loadDetail` 成功后计算：

```js
const me = app.globalData.uid
const isOwner = !!(me && work && work.uid === me)
```

WXML 按 `isOwner` 分支：

**作者视角**
- 不渲染作者头像、作者昵称、关注按钮（整块作者信息区不出现）。
- 在原作者行位置改为一行：**状态标签** + 右侧 **「更多」** 按钮。
- 状态标签为胶囊（`padding:6rpx 20rpx`、`border-radius:24rpx`、字号 `22rpx`）：

| 状态 | 文字色 | 背景 |
|---|---|---|
| 展示 | `#1AA260` | `#E8F8EF` |
| 待审核 | `#FF8F1F` | `#FFF3E6` |
| 隐藏 | `#9499A0` | `#F2F3F5` |
| 已驳回 | `#FB7299` | `#FFE8EF` |

- 「更多」按钮：`wx.showActionSheet({ itemList: ['编辑作品', '删除作品'] })`
  - 选「编辑作品」→ `wx.navigateTo({ url: '/pages/workEdit/workEdit?pid=' + pid })`
  - 选「删除作品」→ `wx.showModal` 二次确认 → `DELETE /pwork/{pid}` → `wx.showToast('已删除')` → `wx.navigateBack()`
  - 删除失败给固定中文提示，不弹后端原文

**他人视角**：完全保持现状（头像/昵称/关注按钮/四连/评论区）。

两种视角都保留：hero 图、标题、副标题、EXIF、四连操作、同款、评论区、底部输入行。

## 5. 新建编辑页 `pages/workEdit/*`

- `app.json` 的 `pages` 数组**末尾追加** `"pages/workEdit/workEdit"`。
- `workEdit.json`：`navigationStyle: "custom"`、`enablePullDownRefresh: false`。
- 结构：自绘头部（左 `‹` 返回 + 居中「编辑作品」）+ 表单区：
  - 封面预览（`mode="aspectFill"`，`height:320rpx`，只读，标注「暂不支持更换封面」）
  - 标题 `input`（`maxlength=100`，占位「作品标题」）
  - 描述 `textarea`（`maxlength=255`，占位「作品描述」）
  - 分类：胶囊单选（横向 `scroll-view`，来自 `/category/list`，选中粉色）
  - 底部固定「保存」按钮（粉色胶囊，`position:fixed; bottom:0` + 安全区），提交中禁用
- 逻辑：
  - `onLoad` 并行读取详情与分类；详情缺失或非本人作品 → 提示「作品不存在或无权编辑」并 2 秒后返回
  - `save()`：本地校验（标题非空、描述 ≤255、分类已选）→ `PUT /pwork/{pid}` body `{ title, desc, imageUrl: 原 vurl, categoryId }`
  - 422（content_rejected）→ 提示「内容未通过安全检查」；400 → 「请检查填写内容」；403 → 「无权编辑该作品」
  - 成功 → `wx.showToast('已保存，等待重新审核')` → 800ms 后 `wx.navigateBack()`

- 不得改动「收藏 / 喜欢 / 设置」三个 tab 的行为与两个列表的独立分页状态。
- 不得改 `loadFavorites` / `switchTab` / 收藏相关请求参数。
- 不得改后端、不得新增其它页面。

- 不得使用 `#3b82f6` `#2563eb` `#6b7280` `#f5f7fb` 旧色值。
