# F11 分类页双视图执行卡

## 1. 目标

把现有占位页 `pages/category/category`（当前只显示「分类页开发中」）做成真页面，采用**单页双视图**：

- **视图 A（分类网格）**：列出全部分类，每张卡片显示分类名 + 该分类作品数；
- **视图 B（分类作品流）**：点某分类后，在当前页内切换到该分类的作品瀑布流，顶部显示分类名并可返回视图 A。

不新增页面、不改路由。

依据：`docs/接口冻结_v1.md` §1.3 #5（`/pwork/list` 的 `category` 参数）、§1.6 #25（`/category/list`）。

## 2. 接口事实（已实测）

| 能力 | 接口 | 返回 |
|---|---|---|
| 分类列表 | `GET /category/list` | `{list:[{pcid,pcname,count}]}`，不带 total |
| 分类作品 | `GET /pwork/list?category=<pcid>&page&size` | `{list,total}`，每项含 `pid/wtitle/vurl/likep/pcname/uname` |
| 作品排序 | `GET /pwork/list?tab=latest|hot&category=<pcid>` | 同上；`tab` 可选，缺省 `recommend` |

注意：`/pwork/list` 只返回 `wstatus='展示'` 的作品。

## 3. 结构与交互

```
pages/category/category
├─ 自绘头部（固定）：左「‹」返回 / 居中标题
│    · 视图 A 标题「分类」
│    · 视图 B 标题为分类名
└─ 内容区（scroll-view）
     ├─ 视图 A：2 列分类网格
     └─ 视图 B：排序行（最新/热门）+ 2 列作品卡 + 分页状态
```

- **返回键行为**：视图 B → 回到视图 A（不发请求、保留已加载数据）；视图 A → `wx.navigateBack()`，无栈时 `wx.switchTab('/pages/workGallery/workGallery')`。
- 视图 A 点卡片：切换 `view='works'`，设置 `pcid`/`pcname`，**首次进入该分类才请求**第一页。
- 视图 B 排序行：`最新` / `热门` 两个胶囊，切换时重置分页并重新请求（`tab=latest|hot`）。默认 `latest`。
- 视图 B 触底加载下一页；`noMore` 后显示「没有更多了」。

## 4. 视觉规格（1px = 2rpx）

| 元素 | 规格 |
|---|---|
| 头部 | 白底，`padding-top` 用 `statusBarH`；高 `88rpx`，`border-bottom:1rpx solid var(--line)` |
| 返回键 | `56rpx` 圆形，`view` 实现（**不要用 `<button>`**，button 默认样式会把它撑成长条黑影，F7 踩过），`hover-class` 按下透明度 `.6` |
| 标题 | `32rpx` / `700` / `var(--ink)` |
| 分类卡片 | 2 列，宽 `calc(50% - 8rpx)`，高 `160rpx`，白底，`border-radius:20rpx`，`box-shadow:0 2rpx 6rpx rgba(0,0,0,.05)`，内容居中：分类名 `30rpx`/`700`/`var(--ink)` + 下方 `22rpx`/`var(--ink-3)` 的「N 件作品」 |
| 分类卡片按下 | `hover-class` 透明度 `.6` |
| 排序胶囊 | 字号 `26rpx`；未选中 `var(--ink-2)`、透明底；选中 `var(--pink)` + `font-weight:700` + `background:var(--pink-soft)` + `border-radius:24rpx` + `padding:6rpx 20rpx` |
| 作品卡 | 与首页一致：图 `mode="widthFix"`、左上分类标签、右下 `♡ N`、标题两行省略、作者行 |
| 空态/失败态 | 居中灰字 + 重试按钮（仅失败时） |

## 5. 状态与数据

`category.js` 需要：

- `view`: `'grid' | 'works'`
- `statusBarH`、`title`（随视图变化）
- `categories`、`categoriesLoading`、`categoriesError`
- `pcid`、`pcname`
- `tab`: `'latest' | 'hot'`（默认 `latest`）
- `list`、`page`、`total`、`size`（10）、`noMore`、`loading`、`loadError`
- `_requestId`：切分类/切排序时丢弃过期响应（同一模式，避免旧请求覆盖新列表）
- 各分类的首页数据不缓存（切分类重新请求即可）

## 7. 人眼验收清单

- [ ] 从「分类」入口进入 → 视图 A，2 列分类卡片，每张显示分类名与「N 件作品」。
- [ ] 分类数、名称、件数与首页卡片上的分类标签一致（共 8 个分类）。
- [ ] 点任一分类型卡片 → **同页**切到该分类作品流，顶部标题变成分类名；**不跳新页面**。
- [ ] 视图 B 顶部有「最新 / 热门」两个胶囊，切换后列表顺序变化且回到第 1 页。
- [ ] 作品卡与首页视觉一致（图、分类标签、点赞数、标题、作者）。
- [ ] 触底加载下一页；到底提示「没有更多了」且不再重复请求。
- [ ] 点作品 → 进详情页；返回后**仍停在原分类与原滚动位置附近**（不被重置到视图 A）。
- [ ] 视图 B 按返回 → 回到视图 A（分类网格仍完好）；视图 A 按返回 → 回到进入前的页面。
- [ ] 断网 → 视图 A 或视图 B 显示失败态 + 重试；恢复后重试成功。
- [ ] 返回键是**左上角小圆点**，不是长条黑影。

## 8. 禁止行为
