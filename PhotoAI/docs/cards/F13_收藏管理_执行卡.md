# F13 收藏与喜欢列表管理执行卡

## 1. 目标

让「我的」页的**收藏**与**喜欢**两个列表可用：

1. 点任意卡片 → 进作品详情页（与在首页点作品完全一致的路径与行为）；
2. 收藏列表每张卡片提供**取消收藏**入口，二次确认后删除并即时从列表移除；
3. 不做收藏分类（按用户要求取消该设想）。

依据：`docs/接口冻结_v1.md` §1.6 #26/#27（`POST/DELETE /favorite/{pid}`）、§1.3 #6（详情）。

## 2. 现状（已核实）

`pages/mine/mine.wxml` 收藏区当前是：

```xml
<view wx:for="{{favorites}}" wx:key="pid" class="pa-card work-card">
  <image class="work-image" src="{{item.imageUrl}}" mode="aspectFill"></image>
  <view class="work-info"><text class="work-title">{{item.wtitle}}</text></view>
</view>
```

- **没有 `bindtap`**，点不进详情；
- 没有删除入口。

## 3. 改法

### 3.1 卡片可点击（收藏 + 喜欢两个列表都要）

两张卡片（`favorites` 与 `likes`）都加：

```xml
data-pid="{{item.pid}}" bindtap="openWork" role="button" aria-label="查看{{item.wtitle}}"
```

`openWork` 方法在 `mine.js` 中**已存在**（跳 `/pages/workDetail/workDetail?pid=`），直接复用，不要重写。

### 3.2 收藏卡片加「取消收藏」

在收藏卡片内右侧加入：

```xml
<view class="fav-remove" data-pid="{{item.pid}}" catchtap="removeFavorite">取消收藏</view>
```

- **必须用 `catchtap`**（不能用 `bindtap`），否则点删除会同时触发卡片跳详情；
- `.fav-remove` 样式：绝对定位右侧垂直居中，`font-size:22rpx`、`color:var(--ink-3)`、`padding:8rpx 12rpx`、`border:1rpx solid var(--line)`、`border-radius:16rpx`、白底；
- 卡片 `.work-card` 需确保 `position: relative`（已有则复用），给右侧按钮留出空间：`.work-info` 右侧 `padding-right:140rpx`，避免标题被按钮压住。

### 3.3 `removeFavorite` 逻辑（`mine.js`）

```js
/**
 * 取消收藏：二次确认后删除记录，成功后本地移除并同步计数。
 * @param {{currentTarget: {dataset: {pid: string}}}} e - 取消收藏事件
 * @returns {Promise<void>} 完成后结束
 */
async removeFavorite(e) {
  const pid = e.currentTarget.dataset.pid
  if (!pid || this._removingFavorite) return
  const confirmed = await new Promise(resolve => wx.showModal({
    title: '取消收藏', content: '确定不再收藏这件作品吗？',
    success: r => resolve(r.confirm), fail: () => resolve(false)
  }))
  if (!confirmed) return
  this._removingFavorite = true
  try {
    await request('/favorite/' + encodeURIComponent(pid), 'DELETE')
    const favorites = this.data.favorites.filter(item => item.pid !== pid)
    this.setData({
      favorites,
      favoritesTotal: Math.max(0, this.data.favoritesTotal - 1)
    })
    wx.showToast({ title: '已取消收藏', icon: 'none' })
  } catch (error) {
    wx.showToast({ title: '操作失败，请重试', icon: 'none' })
  } finally {
    this._removingFavorite = false
  }
},
```

要求：
- 请求失败**不要**把本地列表改掉；
- 成功后如果列表空了，页面自然进入空态（`favorites.length === 0`）；
- 不要重新请求整页（避免分页错位），只做本地移除 + 计数减一。

### 3.4 喜欢列表不加删除

「喜欢」列表只做「可点击进详情」，**不提供取消点赞入口**（用户只要求收藏可管理）。
