# F14 作者切换作品可见性（前端）执行卡

## 1. 目标

在作品详情页的作者视角里，把「更多」菜单扩成三项：**设为隐藏 / 设为展示**（按当前状态二选一）、编辑作品、删除作品。

后端接口已就绪：`PUT /pwork/{pid}/status`，body `{status: '展示'|'隐藏'}`，权限仅作者本人。
待审核 / 已驳回的作品**不允许**由作者改状态（后端返回 409），因此这两项在菜单里不出现。

依据：`docs/接口冻结_v1.md` §1.3 v1.2 扩展（B1）；`docs/cards/B1_作者查看与可见性_执行卡.md` §4。

## 3. 改法

### 3.1 `openMore` 改为动态菜单

```js
openMore() {
  const me = app.globalData.uid
  const work = this.data.work
  if (!this.data.isOwner || !me || !work || work.uid !== me || this._deletingWork) return

  // 只有「展示」「隐藏」两种状态允许作者自己切换；待审核/已驳回必须走审核。
  const canToggle = work.wstatus === '展示' || work.wstatus === '隐藏'
  const toggleLabel = work.wstatus === '展示' ? '设为隐藏' : '设为展示'
  const actions = canToggle ? [toggleLabel, '编辑作品', '删除作品'] : ['编辑作品', '删除作品']

  wx.showActionSheet({
    itemList: actions,
    success: result => {
      if (this._unloaded) return
      const label = actions[result.tapIndex]
      if (label === toggleLabel && canToggle) {
        this.toggleVisibility(work.wstatus === '展示' ? '隐藏' : '展示')
      } else if (label === '编辑作品') {
        this._refreshAfterEdit = true
        wx.navigateTo({ url: '/pages/workEdit/workEdit?pid=' + encodeURIComponent(this._pid) })
      } else if (label === '删除作品') {
        this.deleteWork()
      }
    }
  })
}
```

**必须按文案分发，不能按 `tapIndex` 写死索引**（菜单项数量会变）。

### 3.2 新增 `toggleVisibility`

```js
async toggleVisibility(status) {
  if (this._togglingStatus || !['展示', '隐藏'].includes(status)) return
  const label = status === '隐藏' ? '隐藏（下架）' : '展示（重新上架）'
  const confirmed = await new Promise(resolve => wx.showModal({
    title: '修改作品状态',
    content: '确定将作品设为「' + label + '」吗？',
    success: r => resolve(r.confirm), fail: () => resolve(false)
  }))
  if (!confirmed || this._unloaded) return
  this._togglingStatus = true
  wx.showLoading({ title: '处理中', mask: true })
  try {
    await request('/pwork/' + encodeURIComponent(this._pid) + '/status', 'PUT', { status })
    if (this._unloaded) return
    wx.hideLoading()
    wx.showToast({ title: status === '隐藏' ? '已下架' : '已上架', icon: 'none' })
    await this.loadDetail(this._pid)   // 重读详情，刷新状态胶囊
  } catch (error) {
    wx.hideLoading()
    if (this._unloaded) return
    const messages = {
      conflict: '当前状态不允许切换',
      not_found: '作品不存在或无权修改'
    }
    wx.showToast({ title: messages[error && error.code] || '操作失败，请重试', icon: 'none' })
  } finally {
    this._togglingStatus = false
  }
},
```

注意：
- 路径是 `/pwork/{pid}/status`，**不是** `/pwork/{pid}`；
- method 必须是 `PUT`；
- body 必须是 `{ status }`；
- 成功后**必须重读详情**（`loadDetail(this._pid)`），否则状态胶囊还是旧值。

### 3.3 不要动的地方

- 他人视角（`isOwner === false`）完全不出现「更多」入口，不得改成任何人都能点；
