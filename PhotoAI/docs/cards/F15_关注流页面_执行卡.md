# F15 关注流页面执行卡

## 1. 目标

把底部 tab「关注」对应的空壳页 `pages/userList/userList`（当前 25 行占位内容）实现成真正的**关注流**：展示「我关注的人发布的展示作品」，可点击进详情、可下拉刷新、可触底分页。

**不新建页面、不改路由**：`app.json`、`custom-tab-bar/index.js`、`pages/login/login.js` 里对 `/pages/userList/userList` 的引用一律不动。

依据：`docs/接口冻结_v1.md` §1.3 #11 `GET /pwork/following`（B4 正在实现，契约已冻结）。

## 2. 接口契约（后端 B4 提供）

```
GET /pwork/following?page=1&size=10     需要登录
响应: { list: Work[], total: N }
Work 字段与 /pwork/list 完全一致：
  pid, uid, wtitle, wdesc, vurl, viewcount, votecount, wstatus, cwtime,
  likep, uname, avatar, pcid, pcname, realLikeCount
错误: 400 invalid_request（page/size 非法）、401 unauthorized（未登录）
```

## 3. 页面结构

```
┌─ 顶部栏（自绘，含状态栏占位，白底，底部 1rpx 分割线）
│   关注                                    ← 居中标题，34rpx 粗体
├─ scroll-view（flex:1，可滚动）
│   ├─ 作品卡片（单列，间距 24rpx）
│   │   ├─ 大图 750rpx 宽 × 500rpx 高，aspectFill，圆角 16rpx
│   │   ├─ 标题 30rpx 粗体，最多 2 行省略
│   │   ├─ 作者行：头像 40rpx + 昵称 24rpx 灰 + 分类标签（pcname，24rpx，粉色浅底）
│   │   └─ 点赞数（♡ + likep，24rpx 灰，右对齐）
│   ├─ 加载中提示 / 加载失败重试 / 空态 / 到底提示
└─ 底部留白 24rpx（tabBar 是自定义组件，不在页面内占位）
```

### 3.1 四种状态与文案（必须全部实现）

| 状态 | 条件 | 渲染 |
|---|---|---|
| 首次加载 | `loading && !list.length` | 「加载中...」 |
| 加载失败 | `error` | 「加载失败」+「点击重试」按钮（view，不用 button） |
| 空态 | `!loading && !error && !list.length` | 「还没有关注的人发布作品」+「去首页看看」按钮（`wx.switchTab` 到首页） |
| 到底 | `noMore && list.length > 0` | 「没有更多了」 |

### 3.2 交互

- **下拉刷新**：`onPullDownRefresh` → 重置 `page=1`、清空列表、重新拉取、`wx.stopPullDownRefresh()`（需要 `userList.json` 里 `enablePullDownRefresh: true`）
- **触底加载**：`onReachBottom` → `page+1` 追加，`noMore` 后不再请求
- **点击卡片**：`wx.navigateTo` 到 `/pages/workDetail/workDetail?pid=` + `encodeURIComponent(pid)`
- **登录校验**：`onShow` 里若 `app.globalData.uid` 为空 → 调用项目已有的 `app.requireLogin('/pages/userList/userList')`，未登录不请求接口、显示登录引导
- **tabBar 高亮**：`onShow` 里调用 `this.getTabBar().setSelected('/pages/userList/userList')`（沿用其它页面写法，先看 `pages/mine/mine.js` 或 `pages/workGallery/workGallery.js` 是怎么写的）

## 4. 数据与请求

```js
data: {
  statusBarH: 0,
  list: [],
  page: 1,
  size: 10,
  total: 0,
  loading: false,
  error: false,
  noMore: false,
  loggedIn: false
}
```

- 图片地址拼法沿用详情页：`app.globalData.baseUrl + (vurl.startsWith('/') ? vurl : '/' + vurl)`
- 请求用项目既有的 `utils/request.js`，签名 `request(path, method, data)`
- **过期响应丢弃**：用自增 `_requestId`，响应回来时比对，避免快速切页/刷新时的旧数据覆盖
- 首次加载在 `onLoad`，`onShow` 里只在「登录态从未登录变为已登录」时重拉
