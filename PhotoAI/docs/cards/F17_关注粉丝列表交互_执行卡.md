# F17 关注/粉丝列表交互执行卡

## 1. 目标

`pages/relation/relation`（关注 / 粉丝列表）补两件事：

1. **点头像或整行进对方主页**（关注列表和粉丝列表都要）；
2. **粉丝列表每行多一个「移除」按钮**，二次确认后把对方从我的粉丝里移除，并即时从列表消失、计数减一。

关注列表**不加**「取关」按钮（这轮不做，避免和详情页的关注按钮语义重复）。

## 2. 接口契约

```
GET    /follow/following?page&size   我关注的人（已有）
GET    /follow/followers?page&size   我的粉丝（已有）
DELETE /follow/follower/{uid}        移除粉丝（B6 新增）
  → { removed: true, followersCount: N }
  404 not_found  该用户不是我的粉丝
  401 unauthorized
```
列表项字段（沿用现有）：`uid`、`uname`（或 `nickname`）、`avatar`、可能含 `bio`。**字段名以实际返回为准**，先读 `relation.js` 里现有的字段映射。

## 3. 改动一：整行可点头像

`relation.wxml` 的 `.relation-row` 上加：

```xml
bindtap="goUser" data-uid="{{item.uid}}" role="button" aria-label="查看{{item.uname}}的主页"
```

`relation.js` 加：

```js
/**
 * 打开列表项对应用户的主页；本人则跳我的页，避免自己看自己的空主页。
 * @param {{currentTarget:{dataset:{uid:string}}}} e 行点击事件
 * @returns {void}
 */
goUser(e) {
  const uid = e.currentTarget.dataset.uid
  const me = app.globalData.uid
  if (!uid) return
  if (uid === me) { wx.switchTab({ url: '/pages/mine/mine' }); return }
  wx.navigateTo({ url: '/pages/userDetail/userDetail?uid=' + encodeURIComponent(uid) })
}
```

## 4. 改动二：粉丝行「移除」

`relation.wxml` 里，**只在 `type === 'followers'` 时**渲染右侧按钮：

```xml
<view wx:if="{{type === 'followers'}}" class="relation-remove"
      catchtap="removeFollower" data-uid="{{item.uid}}"
      role="button" aria-label="移除粉丝{{item.uname}}">移除</view>
```

**必须 `catchtap`**，否则点移除会同时触发整行跳转。

`relation.js` 加：

```js
/**
 * 移除一个粉丝：二次确认后调用接口，成功后本地移除并同步计数。
 * @param {{currentTarget:{dataset:{uid:string}}}} e 移除按钮事件
 * @returns {Promise<void>} 完成后结束
 */
async removeFollower(e) {
  const uid = e.currentTarget.dataset.uid
  if (!uid || this._removingFollower) return
  const confirmed = await new Promise(resolve => wx.showModal({
    title: '移除粉丝',
    content: '移除后对方将不再出现在你的粉丝列表中，确定吗？',
    success: r => resolve(r.confirm), fail: () => resolve(false)
  }))
  if (!confirmed || this._unloaded) return
  this._removingFollower = true
  try {
    const res = await request('/follow/follower/' + encodeURIComponent(uid), 'DELETE')
    if (this._unloaded) return
    const list = this.data.list.filter(item => item.uid !== uid)
    const total = res && res.data && typeof res.data.followersCount === 'number'
      ? res.data.followersCount
      : Math.max(0, this.data.total - 1)
    this.setData({ list, total })
    wx.showToast({ title: '已移除', icon: 'none' })
  } catch (error) {
    if (this._unloaded) return
    wx.showToast({ title: '移除失败，请重试', icon: 'none' })
  } finally {
    this._removingFollower = false
  }
},
```

**失败时不改本地列表**。

## 5. 样式（`relation.wxss`）

- `.relation-row` 需要 `position: relative`（如果移除按钮用绝对定位）；
- `.relation-remove`：右侧竖排居中，`font-size:22rpx`、`color:` 用现有变量（如 `--ink-3`）、`padding:8rpx 16rpx`、`border:1rpx solid var(--line)`、`border-radius:16rpx`；
- 行内文字区域加右内边距，避免被按钮压住；
- **不得硬编码颜色**，只用 `app.wxss` 里已有的变量。
