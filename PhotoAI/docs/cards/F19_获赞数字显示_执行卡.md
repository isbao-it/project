# F19 获赞数字显示执行卡

## 1. 目标

把「获赞」从硬编码的 `—` 换成真实数字：

1. **我的页**统计栏「获赞」→ 显示 `GET /user/{自己uid}` 返回的 `likedTotal`；
2. **他人主页**统计行加一格「获赞」，同样取 `likedTotal`。

## 2. 接口

```
GET /user/{uid}  → { ..., worksCount, followingCount, followersCount, likedTotal, followed, showFavorites, showLikes }
```
`likedTotal` 由 B7 提供：该用户所有**展示**作品的 `likep` 之和。后端可能尚未重启，拿不到就保持 `—`。

## 3. 改动一：我的页

`pages/mine/mine.js` 的 `loadStats()`：

- 现有两个请求（`/follow/following`、`/follow/followers`）保持不变；
- **新增第三个请求** `GET /user/{自己uid}`（uid 取 `app.globalData.uid`），复用同一个 `_statsRequestId` 竞态控制；
- 成功后 `setData({ likedTotal: res.data.likedTotal })`；失败或字段缺失 → 保持 `'—'`；
- **不要用 `|| 0` 兜底**，缺失就是未知，显示 `—`。

`pages/mine/mine.wxml:17` 附近，把写死的 `—` 换成绑定：

```xml
<text class="stat-number">{{likedTotal}}</text>
```

`data` 里加初始值 `likedTotal: '—'`。

`openRelation` 的 `data-type="likes"` 保持不变（那是跳「喜欢列表」，与获赞总数无关，不要混）。

## 4. 改动二：他人主页

`pages/userDetail/userDetail.wxml` 的统计行，在「作品 / 关注 / 粉丝」之间或之后加一格「获赞」，绑定 `user.likedTotal`（缺失显示 `—`）。

注意：
- 若统计行是三个 `flex:1` 的格子，加第四个要保持一行四格等宽（`flex:1`），不要换行；
- 获赞那一格**不可点击**（没有对应列表页），不要绑 `bindtap`；
- 其余三格的点击行为不变。
