# F1 底座与登录执行卡

## 1. 目标与用户路径

目标：游客可浏览，微信登录后可进入本人资料和作品，四个底部入口可用。
步骤：打开登录页选择游客浏览 → 首页 → 点击关注/发布/我的引导微信登录 → 返回目标入口 → 我的编辑资料或退出。
依据：`../接口冻结_v1.md` v1.1 §1.2、§1.3、§2；后端契约可用后执行，本卡不实现后端。
tabBar 固定为「首页/关注/发布/我的」，依次绑定已注册的 workGallery/userList/workList/mine。
为不改 pages 注册表，明确将 userList 旧用户管理页改为关注占位、workList 旧作品管理页改为发布占位；不删除页面文件。
关注实际数据由后续卡填，发布功能由 F3 填；占位只显示说明，不请求旧管理接口、不伪造列表。

## 3. 依赖的后端接口

- POST `/auth/wxlogin`：JSON code；data.token/uid/isNew，不能假定返回 role/uname；code 来自 wx.login。
- GET `/user/info`：Bearer token；data.uid/nickname/avatar/bio/role，兼容 uname 等字段只读。
- PUT `/user/profile`：JSON nickname（非空、≤50）/bio（≤255、允许空串）；data 为更新后本人资料；不传 null。
- GET `/pwork/list`：query tab=recommend、page/size；data.list/total，作品 pid/wtitle/vurl/wstatus。
- GET `/pwork/mine`：Bearer token；query status（可省略）、page/size；data.list/total，作品四种状态，uid 不由客户端传。
共用：ID 保持字符串；分页 page≥1、size=1–50；不读顶层 total，不按数字业务码或 msg 分支。

- [ ] 清缓存打开小程序并选游客浏览 → 首页及网络面板 → 可浏览，未调用登录或旧管理接口。

- [ ] 点击微信登录后再连点 → 请求及页面状态 → 只提交一次 code，成功保存 token/uid，资料加载后回原目标。
