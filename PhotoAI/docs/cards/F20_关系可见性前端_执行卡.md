# F20 关系可见性前端执行卡

## 1. 目标

三件事：

1. **设置页扩到 4 个开关**：收藏可见、喜欢可见、关注可见、粉丝可见；
2. **修一个真 bug**：在他人主页点「关注 / 粉丝」数字，现在跳的是**自己的**关注/粉丝列表；应改为看**对方**的；
3. **不可见时数字显示 `—`**，且点击给出提示而不是跳转。

## 2. 接口契约（B8 提供）

```
GET  /user/{uid}                 → 追加 showFollowing / showFollowers
GET  /user/{uid}/following       登录；403（对方关闭且非本人）
GET  /user/{uid}/followers       登录；403
PUT  /user/privacy               B { visFavorite, visLike, visFollowing, visFollowers } 四个布尔全必填
GET  /follow/following           本人（已有，保持不变）
GET  /follow/followers           本人（已有，保持不变）
```

## 3. 改动一：设置页四个开关

`pages/mine/mine.wxml` 的 settings 分支，把现有的两个开关扩成四个：

| 开关 | 绑字段 | 说明文案 |
|---|---|---|
| 收藏可见 | `visFavorite` | 开启后别人能在你的主页看到你的收藏 |
| 喜欢可见 | `visLike` | 开启后别人能在你的主页看到你的喜欢 |
| 关注可见 | `visFollowing` | 开启后别人能看到你关注了谁 |
| 粉丝可见 | `visFollowers` | 开启后别人能看到谁关注了你 |

`pages/mine/mine.js`：
- `data` 加 `visFollowing: true, visFollowers: true`；
- `loadPrivacy`（或现有读取逻辑）从 `GET /user/info` 取四个值，缺省 `true`；
- `togglePrivacy` 扩展为处理四个字段之一，**提交时四个字段全部带上**（未改的保持当前值）；
- 失败回滚到之前的四个值。

## 4. 改动二：relation 页支持查看他人

`pages/relation/relation.js` 的 `onLoad`：

```js
// 允许从他人主页带 uid 进入；缺省或等于自己时走本人接口。
const targetUid = options.uid || ''
this._targetUid = targetUid && targetUid !== app.globalData.uid ? targetUid : ''
```

请求地址：

```js
const base = this._targetUid
  ? '/user/' + encodeURIComponent(this._targetUid)
  : '/follow'
const url = base + (this.data.type === 'followers' ? '/followers' : '/following')
```

注意：
- 本人路径仍是 `/follow/following`、`/follow/followers`（不要改成 `/user/{自己}/following`，保持既有契约）；
- 他人路径是 `/user/{uid}/following`、`/user/{uid}/followers`；
- 看他人列表时**不显示「移除」按钮**（`wx:if="{{type === 'followers' && !isOthers}}"`，`isOthers` 由 `_targetUid` 决定）；
- 403（对方关闭可见）→ 显示「该用户未公开此列表」，不要显示「加载失败」；
- 标题：本人「关注 / 粉丝」，他人「TA 的关注 / TA 的粉丝」。

## 5. 改动三：他人主页的三个数字

`pages/userDetail/userDetail.wxml`：

- 「关注」数字：`{{user.showFollowing ? user.followingCount : '—'}}`
- 「粉丝」数字：`{{user.showFollowers ? user.followersCount : '—'}}`
- 点击时带上目标 uid：

```js
openRelation(e) {
  const type = e.currentTarget.dataset.type
  if (!['following', 'followers'].includes(type)) return
  // 对方关闭该列表时只提示，不跳转。
  if (type === 'following' && this.data.user.showFollowing === false) {
    wx.showToast({ title: 'TA 未公开关注列表', icon: 'none' }); return
  }
  if (type === 'followers' && this.data.user.showFollowers === false) {
    wx.showToast({ title: 'TA 未公开粉丝列表', icon: 'none' }); return
  }
  wx.navigateTo({ url: '/pages/relation/relation?type=' + type + '&uid=' + encodeURIComponent(this.data.uid) })
}
```

**必须带 `uid`**，否则又跳回自己的列表（这是当前 bug 的根因）。

`worksCount`（作品）与 `likedTotal`（获赞）的点击/显示行为保持不变。
