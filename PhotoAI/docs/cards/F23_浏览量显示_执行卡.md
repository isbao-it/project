# F23 浏览量显示执行卡

## 1. 目标

把作品的浏览量（`viewcount`，即"播放量/浏览次数"）显示出来。目前接口一直在返回该字段，**但四个页面一个都没渲染**。

1. **详情页**：在作者信息区下方显示浏览量；
2. **作品卡片**（首页 / 分类 / 关注流）：图片左下角显示浏览量，与右下角的 ♡ 点赞数对称。

## 2. 现状（已核实）

- 数据：46 件展示作品，`viewcount` 范围 6~1129，平均 508，合计 23379。
- 详情接口每次成功读取会原子 +1（`incrementView`），返回的是增加后的值。
- 四个页面（`workGallery` / `workDetail` / `category` / `userList`）的 wxml 里 **`viewcount` 命中数为 0**。
- 列表项与详情 `work` 对象都已含 `viewcount`（数字）。

## 3. 改动

### 3.1 详情页（`pages/workDetail`）

在**作者行（头像 + 昵称 + 关注按钮）下方**加一行统计：

```
♡ 169    ☆ 45    👁 1129
```

实现建议（保持现有视觉语言，不要引入新配色）：

```xml
<view class="detail-stats">
  <text class="stat-item">♡ {{likeCount}}</text>
  <text class="stat-item">☆ {{favoriteCount === null ? '—' : favoriteCount}}</text>
  <text class="stat-item">{{viewCount}} 次浏览</text>
</view>
```

- `viewCount` 新加进 `data`，在 `loadDetail` 成功时从 `work.viewcount` 赋值；**不要**在点击操作时改动它（浏览量只由服务端读取时自增）；
- `favoriteCount` 沿用 F18 的规则：`null` 显示 `—`，**不得用 0 兜底**；
- 样式与副标题同级：`font-size:24rpx`、`color:` 用现有次级文字变量、三项之间 `margin-right` 隔开。

### 3.2 作品卡片（三个页面）

卡片图片目前右下角有 ♡ 点赞数，在**图片左下角**加浏览量：

```xml
<view class="card-views">{{item.viewcount}}</view>
```

样式要求（三页一致）：

```css
.card-views {
  position: absolute;
  left: 16rpx;
  bottom: 12rpx;
  padding: 2rpx 10rpx;
  border-radius: 12rpx;
  font-size: 22rpx;
  color: #fff;
  background: rgba(0, 0, 0, 0.35);
}
```

- 父容器（图片外层）需 `position: relative`，**若已存在则不要重复加**；
- 三页（`workGallery` / `category` / `userList`）用同一个 class 名与同一套数值，保证视觉一致；
- 千位以上不做「1.2万」缩写，直接显示数字（避免引入格式化逻辑与歧义）。

## 5. 验收（必须真实执行并贴原始输出）

1. `grep -n "viewcount" pages/workDetail/workDetail.wxml pages/workGallery/workGallery.wxml pages/category/category.wxml pages/userList/userList.wxml` —— **四个文件都要有命中**；
2. `grep -n "viewCount" pages/workDetail/workDetail.js` —— 有赋值语句，并打印 `loadDetail` 里那一行；
3. 打印三页 `.card-views` 的样式规则，确认四页（含详情）数值一致、都是 `rgba(0,0,0,0.35)` 级别的浅底白字；
4. 确认详情页 `favoriteCount` 仍是 `=== null ? '—'`，未用 `|| 0` 兜底；
5. 文件 UTF-8 无 BOM，旧色值（`#3b82f6` `#2563eb` `#6b7280` `#f5f7fb`）命中数 0；
6. WXML 中 HTML 实体命中数 0；
7. `node --check pages/workDetail/workDetail.js` 退出码 0。
