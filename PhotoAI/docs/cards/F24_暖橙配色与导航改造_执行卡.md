# F24 暖橙配色 + 关注上移 + 相机图标执行卡

## 1. 目标

三件事一起做（都动 `custom-tab-bar`，拆开会互相覆盖）：

1. **配色从 B 站粉换成暖橙**：`#FB7299` → `#FF6B35`；
2. **「关注」从底部栏移到首页顶部排序行**，底部栏变为 3 项（首页 / 发布 / 我的）；
3. **底部「发布」图标换成相机**（现在是加号）。

## 2. 现状（已核实）

**全局变量**（`app.wxss` 第 5–14 行）：
```css
--pink: #FB7299;  --pink-soft: #FFE8EF;  --blue: #00AEEC;
--ink: #18191C;   --ink-2: #61666D;      --ink-3: #9499A0;
--bg: #F6F7F8;    --card: #FFFFFF;       --line: #EDEFF2;
```

**底部栏**（`custom-tab-bar/index.js` 第 12–17 行）4 项：
```
首页 / 关注(userList) / 发布 / 我的
```
图标是 **base64 内联 SVG**，颜色写死在 data URI 里（未选中 `#9499A0`、选中 `#FB7299`）。
发布图标是一条竖线 + 一条横线（加号），class `tab-icon-publish`。

**首页排序行**（`workGallery.wxml` 第 10–13 行）：
```xml
<button wx:for="{{tabs}}" ...>推荐/最新/热门</button>
<view class="gallery-tab gallery-tab-entry" bindtap="goCategory">分类</view>
```
`data.tabs` 在 `workGallery.js` 第 11–13 行，只有 recommend/latest/hot。

**关注流页**（`pages/userList`）目前是 **tab 页**，`onShow` 里调用了
`this.getTabBar().setSelected('/pages/userList/userList')` —— **改成普通页后这行会报错，必须删除**。

## 3. 改动

### 3.1 配色（`app.wxss`）

只改**变量值**，变量名保持不变（避免大面积改动）：

```css
page {
  /* 主色：暖橙（原 B 站粉 #FB7299，改为与摄影暖调协调的橙） */
  --pink: #FF6B35;
  --pink-soft: #FFF0EA;
  /* 辅助色：琥珀（原 B 站蓝 #00AEEC） */
  --blue: #FFB020;
  /* 文字与背景：近黑略带暖调，底色极浅暖灰 */
  --ink: #1A1410;
  --ink-2: #5C534D;
  --ink-3: #9A8F88;
  --bg: #FAF8F7;
  --card: #FFFFFF;
  --line: #EDE8E5;
  background-color: #FAF8F7;
}
```

同时把 `app.wxss` 里其它**硬编码**的 `#F6F7F8` / `#EDEFF2` / `#61666D` / `#9499A0` / `#FB7299` / `#00AEEC`
一并替换成对应新值（按语义：背景→`#FAF8F7`、分割线→`#EDE8E5`、次要文字→`#5C534D`、三级文字→`#9A8F88`）。

### 3.2 底部栏 3 项（`custom-tab-bar/index.js` + `app.json`）

`list` 改为：

```js
list: [
  { pagePath: '/pages/workGallery/workGallery', text: '首页', key: 'home' },
  { pagePath: '/pages/workList/workList', text: '发布', key: 'publish' },
  { pagePath: '/pages/mine/mine', text: '我的', key: 'mine' }
]
```

`app.json` 的 `tabBar.list` 同步删除 `pages/userList/userList`（但 **`pages` 数组里保留该页**，它仍要被 `navigateTo` 访问）。

### 3.3 首页排序行加「关注」（`workGallery.wxml` + `.js`）

在「分类」之前插入：

```xml
<view class="gallery-tab gallery-tab-entry" bindtap="goFollowing" role="link" aria-label="关注">关注</view>
```

`workGallery.js` 加：

```js
/**
 * 打开关注流。关注流已从底部栏移到顶部入口，用 navigateTo 保留返回栈。
 * @returns {void}
 */
goFollowing() {
  wx.navigateTo({ url: '/pages/userList/userList' })
}
```

最终顺序：**推荐 / 最新 / 热门 / 关注 / 分类**。

### 3.4 关注流页改造（`pages/userList`）

- **删除** `onShow` 里的 `this.getTabBar().setSelected(...)`（非 tab 页没有 tabBar，调用会抛错）；
- 顶部栏**加返回按钮**（用 `<view>`，`bindtap="goBack"`，`wx.navigateBack`，无栈时回首页）：
  ```js
  goBack() {
    const pages = getCurrentPages()
    if (pages.length > 1) wx.navigateBack()
    else wx.switchTab({ url: '/pages/workGallery/workGallery' })
  }
  ```
- 其余逻辑（下拉刷新、触底分页、四状态、`_requestId`）**一律不动**。

### 3.5 发布图标换相机（`custom-tab-bar/index.wxss`）

把 `.tab-icon-publish` 与 `.tab-item-active .tab-icon-publish` 的 base64 SVG 换成**相机图标**：

```svg
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="#9A8F88" stroke-width="1.8" stroke-linecap="round" stroke-linejoin="round">
  <path d="M23 19a2 2 0 0 1-2 2H3a2 2 0 0 1-2-2V8a2 2 0 0 1 2-2h4l2-3h6l2 3h4a2 2 0 0 1 2 2z"/>
  <circle cx="12" cy="13" r="4"/>
</svg>
```

选中态把 `stroke` 换成 `#FF6B35`。两段都要重新做 **base64 编码**（用 Python `base64.b64encode`，不要手工拼）。

保留现有 `.tab-publish` 的圆形高亮底（只换图标内容与配色），布局尺寸不变。

### 3.6 其余 SVG 颜色同步

`custom-tab-bar/index.wxss` 里所有 base64 SVG 的 `#9499A0` → `#9A8F88`、`#FB7299` → `#FF6B35`
（首页、我的、关注残留=已删除），同样用 Python 重新编码。
