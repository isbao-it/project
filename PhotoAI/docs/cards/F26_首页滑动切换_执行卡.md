# F26 首页改为滑动切换（推荐/最新/热门/关注）执行卡

## 1. 目标

首页顶部的「推荐 / 最新 / 热门 / 关注」改为**页内滑动切换**：

- 点 tab → 切到对应内容；
- **左右滑动 → 同样切换 tab**；
- 每个 tab **独立**的分页、加载状态、列表数据、滚动位置；
- 「关注」不再跳转到 `pages/userList`（保留该页但首页不再引用它）；
- 「分类」仍是独立入口（跳转，不参与滑动）。

## 2. 现状（已核实）

`pages/workGallery/workGallery.wxml` 当前结构：

```xml
<view class="gallery-header">…logo / 搜索…</view>
<view class="gallery-sticky">           <!-- 吸顶 -->
  <view class="gallery-tabs">
    <button wx:for="{{tabs}}" …>推荐/最新/热门</button>
    <view class="gallery-tab gallery-tab-entry" bindtap="goFollowing">关注</view>   <!-- F24 新增，跳页 -->
    <view class="gallery-tab gallery-tab-entry" bindtap="goCategory">分类</view>
  </view>
</view>
<view class="gallery-container">…单列表 + 四状态…</view>
```

- `data.tabs` 只有 recommend / latest / hot（`workGallery.js` 第 11–13 行）
- 单一列表状态（`list` / `page` / `total` / `loading` / `error` / `noMore`）
- 页面级滚动（`app.json` 里该页 `enablePullDownRefresh`），`onPullDownRefresh` / `onReachBottom` 在 js 里
- 关注接口：`GET /pwork/following?page&size`（**需要登录**，未登录 401）
- 作品接口：`GET /pwork/list?tab=recommend|latest|hot&page&size`（匿名可访问）

## 3. 目标结构

```
┌ gallery-page (height:100vh, flex column)
│ ├ 头部（logo/搜索）          固定
│ ├ 吸顶排序行                  固定
│ └ swiper (flex:1, min-height:0)    ← 关键：必须能收缩
│     ├ swiper-item[推荐] → scroll-view(list, 刷新, 触底)
│     ├ swiper-item[最新] → scroll-view(...)
│     ├ swiper-item[热门] → scroll-view(...)
│     └ swiper-item[关注] → scroll-view(...)
```

### 3.1 WXML 骨架

```xml
<swiper class="gallery-swiper" current="{{tabIndex}}" bindchange="onSwiperChange" duration="220">
  <swiper-item wx:for="{{tabs}}" wx:key="value">
    <scroll-view class="gallery-scroll" scroll-y
                 refresher-enabled
                 refresher-triggered="{{states[item.value].refreshing}}"
                 bindrefresherrefresh="onRefresh"
                 data-tab="{{item.value}}"
                 bindscrolltolower="onLoadMore"
                 data-tab="{{item.value}}">
      <!-- 现有卡片列表渲染逻辑，数据源改为 states[item.value].list -->
      <!-- 四状态：首次加载 / 失败重试 / 空态 / 到底，也读 states[item.value] -->
    </scroll-view>
  </swiper-item>
</swiper>
```

注意：`bindscrolltolower` 与 `bindrefresherrefresh` 都要能拿到是哪个 tab 在滚动，用 `data-tab` 传。

### 3.2 data 结构

```js
tabs: [
  { value: 'recommend', label: '推荐' },
  { value: 'latest',    label: '最新' },
  { value: 'hot',       label: '热门' },
  { value: 'following', label: '关注' }
],
tabIndex: 0,
tab: 'recommend',
states: {
  recommend: { list: [], page: 0, total: 0, loading: false, error: false, noMore: false, refreshing: false },
  latest:    { …同上… },
  hot:       { …同上… },
  following: { …同上… }
}
```

### 3.3 请求

| tab | 接口 | 登录要求 |
|---|---|---|
| recommend / latest / hot | `/pwork/list?tab=<tab>&page=&size=` | 匿名可访问 |
| following | `/pwork/following?page=&size=` | **需要登录**；未登录（401）→ 该 tab 显示「登录后查看关注」+ 登录按钮，不报错 |

**每个 tab 独立的 `_requestId`**（如 `this._reqId.recommend`），避免切换时旧响应覆盖新数据。

### 3.4 交互

- **点 tab**：`onTabChange` → `setData({ tab, tabIndex })`；若该 tab 从未加载过（`page === 0` 且未 loading）则发起首屏请求。
- **滑动**：`onSwiperChange` 取 `e.detail.current` → 同步 `tab` / `tabIndex` → 同样懒加载。
- **下拉刷新**：`onRefresh` 按 `data-tab` 重置该 tab 的 `page=1`、清空列表、重新拉取；结束时把该 tab 的 `refreshing` 置回 false。
- **触底加载**：`onLoadMore` 按 `data-tab` 判断 `noMore` / `loading` 后追加下一页。
- **滚动位置**：每个 swiper-item 内的 scroll-view 天然保留各自位置，不要去手动重置。
- **关注 tab 的登录态**：`app.globalData.uid` 为空时，不请求接口，直接显示登录引导；登录成功后回到首页时该 tab 重新拉取。

### 3.5 样式要点（`workGallery.wxss`）

```css
.gallery-page   { height: 100vh; display: flex; flex-direction: column; }
.gallery-swiper { flex: 1 1 auto; min-height: 0; }   /* min-height:0 必须有，否则 swiper 撑出视口 */
.gallery-scroll { height: 100%; }
```

- 现有 `.gallery-container` 的内边距与卡片间距保留在 scroll-view 内部；
- **不要**给 swiper 写死像素高度（1000rpx 之类），必须 flex 撑满剩余空间。

### 3.6 移除的东西

- `goFollowing()` 方法（首页不再跳转关注流页）
- 页面级 `onPullDownRefresh`（改由每个 scroll-view 的 refresher 负责）；若 `app.json` 里该页配了 `enablePullDownRefresh`，一并去掉
- 页面级 `onReachBottom`（改由每个 scroll-view 的 `bindscrolltolower`）
- 单一的 `list` / `page` / `total` / `loading` / `error` / `noMore` 顶层字段（迁进 `states`）

**保留**：`pages/userList/userList` 页面本身（不删文件、不改它），只是首页不再有入口。
