# F2 画廊与详情执行卡

## 1. 目标与用户路径

目标：游客可按排序与分类浏览公开作品，进入详情查看图片、作者和 EXIF。
步骤：首页 → 推荐/最新/热门 → 分类筛选 → 触底翻页 → 点作品 → 查看详情与大图 → 返回原列表。
依据：`../接口冻结_v1.md` v1.1 §1.3、§1.6、§2；依赖 F1 的首页路由和请求底座。
仅展示后端返回的展示作品；推荐排序未冻结，不宣称已实现个性化推荐。

## 2. 页面/文件清单

以下路径相对 `WeChat Mini Program/pg/`；新增文件：无；仅允许修改下列文件。
- 修改 `pages/workGallery/workGallery.wxml`：排序、分类、作品网格、加载/空态/失败重试。
- 修改 `pages/workGallery/workGallery.js`：分类读取、分页、筛选重置、过期响应丢弃及字符串 pid 跳转。
- 修改 `pages/workGallery/workGallery.wxss`：网格、缩略图及状态布局。
- 修改 `pages/workGallery/workGallery.json`：页面局部标题与刷新声明。
- 修改 `pages/workDetail/workDetail.wxml`：图片、标题/描述、作者、计数、EXIF 和三个空预留段。
- 修改 `pages/workDetail/workDetail.js`：读取 data.work/exif/author，图片预览和错误状态。
- 修改 `pages/workDetail/workDetail.wxss`：详情布局与缺省显示；预留空段不得占可见高度。
- 修改 `pages/workDetail/workDetail.json`：页面局部标题与声明。
workDetail.wxml 必须分别建可检索的 card05/card06/card07 标记及空容器，依次留给评论点赞、分类收藏同款、关注；本卡不填内容、不绑事件、不发相关请求。
作者信息只展示；不把普通用户导向现有 /user/{uid} 他人资料接口。

## 3. 依赖的后端接口

- GET `/category/list`：无参数；data.list，每项 pcid/pcname/count；没有 total。
- GET `/pwork/list`：query tab=recommend/latest/hot、category（分类 pcid，可省略）、page/size；data.list/total。
- GET `/pwork/{pid}`：路径 pid 为字符串；data.work/exif/author；work 含 wtitle/wdesc/vurl/viewcount/likep/votecount/cwtime；author 含 nickname/avatar。
EXIF 只含 focal/aperture/shutter/iso/lens/camera；exif 或 author 可为 null，单项可为 null；详情浏览量取返回值，不在客户端额外加一。
共用：HTTP 2xx 且 code==='ok'；page≥1、size=1–50；不传旧 wtitle/uname/wstatus/pageNum/pageSize，不调用旧视图列表。

## 4. 人眼验收清单

- [ ] 游客打开首页 → 请求与网格 → 无需登录，读取 data.list/total，仅显示展示作品。
- [ ] 切换推荐/最新/热门 → 参数及列表 → 分别传合法 tab，回到第1页，不混入上次排序结果。
- [ ] 点分类后迅速换另一分类并制造首请求延迟 → 请求与最终列表 → category 使用 pcid，仅保留最后所选分类数据。
- [ ] 连续触底至末页再下拉刷新 → 页码、条目与加载提示 → 同页不重发，无重复作品，末页停止，刷新回第1页。
- [ ] 分类/作品无数据或断网，再恢复并点重试 → 提示与列表 → 空态和失败态可区分，重试成功，刷新动画结束。
- [ ] 点击作品并预览大图、返回 → 详情与原列表位置 → 标题/描述/计数来自 work，原列表筛选与已加载项保留，图片正确。
- [ ] 分别打开完整 EXIF、缺 EXIF、缺作者的作品 → 六项参数及缺省文字 → 有值正确显示，缺值用“暂无/未知”，无 null/undefined 文案。
- [ ] 打开不存在或非展示 pid → 详情区域 → 显示不可访问提示，可返回，无旧作品残留，不循环请求。
- [ ] 查看详情并检查 WXML → 预留段与网络 → card05/06/07 各有独立空段，无可见空洞，无互动/同款/关注请求。

## 5. 禁止行为

- 不得改后端 `src/main`、任何既有测试；不得删旧页面；不改 tabBar 之外全局配置，本卡也不改 tabBar。
- 不新增组件/依赖，不填 card05/06/07，不实现搜索、互动、收藏、同款或关注，不增加冻结表外筛选参数。
- 不使用 git，不修改上列之外文件；接口缺口须记录，禁止用假数据冒充联调成功；未执行的人眼项标注未验证。
