# F4 视觉底座执行卡

## 1. 目标与用户路径

目标：把全局视觉从默认灰蓝（`#3b82f6` / Tailwind 灰阶）切换为 `docs/preview/photoai_mockup.html` 定义的 B 站式粉色设计系统，并提供后续 F5–F9 共用的样式底座与底部导航。

用户路径：任意 tab 页 → 顶部导航栏为白底黑字、页面底色为 `#F6F7F8` → 底部 4 栏导航为粉色选中态、中间「发布」为粉色圆角方块。

本卡**只做底座与 tabBar**，不改任何 `pages/*` 的布局与结构；页面级还原由 F5–F9 分别执行。

依据：`docs/preview/photoai_mockup.html`（第 9–11 行设计变量、第 54–61 行 tabBar、第 29–33 行头部）。本卡不涉及后端接口。

## 2. 页面/文件清单

以下路径相对 `WeChat Mini Program/pg/`。新增文件：无；仅允许修改下列文件。

- 修改 `app.json`：`window.navigationBarBackgroundColor` 改 `#FFFFFF`、`navigationBarTextStyle` 改 `black`、`backgroundColor` 改 `#F6F7F8`、`backgroundColorTop/Bottom` 同步；`tabBar.color` 改 `#9499A0`、`selectedColor` 改 `#FB7299`、`backgroundColor` 保持 `#FFFFFF`。
- 修改 `custom-tab-bar/index.wxml`：按第 3 节结构重写。

不得修改 `pages/` 下任何文件；不得删除 `images/*.png`（保留以免其他引用断裂）；不得新增 npm 依赖、组件或字体文件。

## 3. 设计规格（唯一视觉来源）

### 3.1 设计变量（共 9 个，写入 `app.wxss` 的 `page{}`）

```
--pink:#FB7299      --pink-soft:#FFE8EF   --blue:#00AEEC
--ink:#18191C       --ink-2:#61666D       --ink-3:#9499A0
--bg:#F6F7F8        --card:#FFFFFF        --line:#EDEFF2
```

尺寸换算：设计稿 1px = 2rpx（750rpx 基准）。

### 3.2 通用类（写入 `app.wxss`，供 F5–F9 复用）

- `.pa-btn-primary`：背景 `var(--pink)`，白字，`border-radius:44rpx`，高 `88rpx`，无边框。
- `.pa-btn-ghost`：白底、`1rpx solid var(--line)`、字色 `var(--ink-2)`。
- `.pa-chips`：`display:flex; gap:16rpx; padding:16rpx 28rpx; background:var(--card); overflow-x:auto; white-space:nowrap`。
- `.pa-chip`：字号 `26rpx`、色 `var(--ink-2)`、`padding:8rpx 4rpx`、`white-space:nowrap`。
- `.pa-chip.on`：色 `var(--pink)`、`font-weight:700`，下方 `32rpx × 6rpx`、`border-radius:4rpx`、背景 `var(--pink)` 的短横线（用 `::after` 绝对定位居中）。
- `.pa-card`：白底、`border-radius:20rpx`、阴影 `0 2rpx 6rpx rgba(0,0,0,.05)`。
- `.pa-ava`：`52rpx` 圆形，背景 `linear-gradient(135deg,#FFB3C7,#FB7299)`。
- `.pa-tag`：绝对定位角标，字号 `20rpx`、白字、背景 `rgba(0,0,0,.42)`、`border-radius:8rpx`、`padding:2rpx 10rpx`。
- `.pa-line`：`1rpx solid var(--line)` 分割线。

### 3.3 底部导航（`custom-tab-bar`）

| 项 | 规格 |
|---|---|
| 容器 | 高 `108rpx` + `env(safe-area-inset-bottom)`，白底，上边框 `1rpx solid var(--line)`，`justify-content:space-around`，`align-items:center` |
| 单个 tab | 高 `56rpx`，宽 `112rpx`，纵向排列，图标与文字间距 `4rpx` |
| 文字 | `20rpx`；未选中 `var(--ink-3)`；选中 `var(--pink)` 且 `font-weight:700` |
| 图标 | `44rpx` 见方；未选中 `#9499A0`，选中 `#FB7299` |
| 关注图标 | **必须为爱心形状**（实心/描边均可，与设计稿 `❤` 一致），不得使用双人/用户群像图标 |
| 中间「发布」 | `80rpx × 56rpx`，`border-radius:16rpx`，背景 `var(--pink)`，白色加号，居中；**该 tab 不渲染任何文字**（设计稿只有一个加号方块）；选中时背景加深为 `#E85F86` |
| 顺序 | 首页 / 关注 / 发布 / 我的，与 `app.json` 的 `list` 顺序一致 |

图标实现：主方案为 `<view>` + `background-image: url("data:image/svg+xml;base64,...")`，四个图标各备灰/粉两版（共 8 段 base64），`background-size:100% 100%`。若真机预览出现不渲染，回退为纯 CSS 绘制（`border`/`border-radius`/`transform` 拼几何形状），两种方案验收标准相同。禁止使用 emoji 或位图 PNG 作为图标。

## 4. 人眼验收清单

- [ ] 打开首页 → 顶部原生导航栏 → 背景纯白、标题黑字、无蓝色底。
- [ ] 任一页面空白处背景 → `#F6F7F8`，与白色卡片有可辨差异，不出现灰紫偏色。
- [ ] 底部导航 → 高度与安全区 → 四个入口文字与图标垂直居中对齐，iPhone 全面屏机型底部不遮挡内容。
- [ ] 切到「关注」→ 选中态 → 该 tab 图标与文字同为 `#FB7299`，其余三项为 `#9499A0`，无错位、无残留蓝色。
- [ ] 切到「发布」→ 中间方块 → 为 `#FB7299` 圆角矩形、白色加号居中，与实际尺寸 80×56rpx 一致。
- [ ] 逐一切换四个 tab → 图标渲染 → 均清晰无锯齿、无破图、无 emoji 彩色字形。
- [ ] 在 `app.wxss` 中把 `--pink` **临时**改成一个明显不同的色值（如 `#00FF00`）→ `.pa-btn-primary` 的背景与底部导航选中态的**文字**随之变色（tab 图标为内联 SVG 固定色，不参与变量联动，这是 §3.3 的既定规格，不算失败）；验完**必须改回** `#FB7299`。
- [ ] 打开任意既有页面（如作品详情）→ 布局 → 除底色与导航栏配色外，内容结构、间距、文案完全不变（本卡不改页面布局）。
