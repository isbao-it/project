# F6 首页视觉还原执行卡

## 1. 目标与用户路径

目标：把首页 `workGallery` 的布局与视觉还原为 `docs/preview/photoai_mockup.html` 第 ① 屏，并按设计稿改为自绘头部（去掉原生导航栏）。

用户路径：进入首页 → 顶部为「PhotoAI」粉色字标 + 搜索占位框 + 圆形头像 → 下方左对齐「推荐/最新/热门」→ 再下方分类横向滑动条 → 双列瀑布流作品卡片（左上分类标签、右下点赞数）→ 触底加载更多。

**本卡只改首页的 UI 结构、样式与必要的取值绑定；F2 已验收的业务行为（请求参数、分页、过期响应丢弃、空态/失败重试）必须原样保留并重新逐条验证。**

依据：`docs/preview/photoai_mockup.html` 第 29–52 行（头部 / chips / 瀑布流）与第 156–204 行（首页 DOM 结构）；`docs/cards/F2_画廊与详情_执行卡.md` §3、§4（业务契约，不得改）。

## 2. 页面/文件清单

以下路径相对 `WeChat Mini Program/pg/`。新增文件：**无**；仅允许修改下列文件。

- 修改 `pages/workGallery/workGallery.wxml`：重写头部、排序、分类、卡片结构。
- 修改 `pages/workGallery/workGallery.wxss`：按 §3 规格重写本页样式。
- 修改 `pages/workGallery/workGallery.js`：仅新增状态栏/胶囊避让的 2 个 data 与对应取值；分类由 `picker` 改为 chip 列表后的选中态绑定；**不得改动** `loadGallery`/`loadCategories`/`onTabChange` 的请求参数与分页逻辑。
- 修改 `pages/workGallery/workGallery.json`：`navigationStyle` 设为 `custom`，保留 `enablePullDownRefresh: true`。

不得修改 `app.wxss`、`app.js`、`custom-tab-bar/*`、其他页面文件、`images/*`。

## 3. 设计规格（唯一视觉来源，1px = 2rpx）

### 3.1 自绘头部

- 页面 `navigationStyle: custom`，头部背景 `#FFFFFF`。
- 头部 `padding: 8rpx 28rpx 20rpx`，`display:flex`，`align-items:center`，`gap:20rpx`。
- 顶部预留状态栏高度，右侧预留胶囊按钮宽度，取值方式：
  ```js
  const info = wx.getWindowInfo()
  const cap = wx.getMenuButtonBoundingClientRect()
  this.setData({ statusBarH: info.statusBarHeight, navRight: info.windowWidth - cap.left + 8 })
  ```
  WXML 用 `style="padding-top:{{statusBarH}}px;padding-right:{{navRight}}px"`。
- `PhotoAI` 字标：`font-size:40rpx`、`font-weight:800`、`color:#FB7299`、`letter-spacing:1rpx`。
- 搜索占位框：`flex:1`、`height:60rpx`、`border-radius:30rpx`、背景 `#F6F7F8`、内文 `24rpx` / `#9499A0`、左内边距 `24rpx`，文案「搜索作品 / 摄影师」并前置放大镜字符。**纯视觉占位，不绑事件、不发请求。**
- **右上角不放头像**：微信胶囊按钮由系统绘制、无法移除，头像与它争位会互相遮挡；原 `pa-ava` 头像节点与 `goProfile` 方法一并移除。

### 3.2 排序（四项平分一行，含分类入口）

- 容器：`display:flex`、`width:100%`、`padding:16rpx 28rpx 0`、背景 `#FFFFFF`。
- **共四项，顺序固定为：推荐 / 最新 / 热门 / 分类**，每项 `flex:1`、`text-align:center`，四等分填满整行，右侧不得留大片空白。
- **该行不可横向滚动**：禁止使用 `overflow-x:auto`、禁止 `<scroll-view>`、禁止复用全局 `.pa-chips`（它自带横向滚动）。
- 每项字号 `28rpx`，未选中 `#61666D`，选中 `#FB7299` + `font-weight:700`。
- 选中项下方短横：`32rpx × 6rpx`、`border-radius:4rpx`、背景 `#FB7299`、水平居中，距文字底 `4rpx`。
- **「分类」是入口不是筛选项**：永不显示选中态、永不加短横；点击后 `wx.navigateTo` 跳 `pages/category/category`，不改变 `tab` 值、不发列表请求。
- 分类数据 `categories` 与 `loadCategories()` 保留（供后续分类页使用），但首页不再渲染分类词条、不再向列表请求传 `category` 参数。

### 3.3 分类词条行（本卡移除）

原「全部 / 风光 / 人像…」横滑行**整体删除**，分类筛选改由 3.6 的独立页面承载。首页 `wxml` 中不得再出现 `scroll-view` 分类行、`category-scroll`、`category-chip`、`categoryError` 渲染块。

### 3.6 分类占位页（本卡新建，仅骨架）

- 新增 4 个文件：`pages/category/category.wxml` / `.wxss` / `.js` / `.json`。
- `app.json` 的 `pages` 数组**末尾追加** `"pages/category/category"`（只允许这一处改动，其余配置一字不动）。
- 页面内容：自绘头部（左侧返回箭头 + 居中标题「分类」，`navigationStyle: custom`）+ 正文区居中一行提示文字「分类页开发中」，样式沿用 F4 的变量与 `.pa-*` 类。
- 返回：`wx.navigateBack()`；若无法返回则 `wx.switchTab('/pages/workGallery/workGallery')`。
- **不实现任何分类列表、不发任何请求、不读取 `categories`**——这一页只是占位，等设计稿到位后另开卡填充。

### 3.4 瀑布流卡片

- 容器 `display:flex; flex-wrap:wrap; justify-content:space-between; padding:16rpx 20rpx 156rpx`。
- 卡片宽 `calc(50% - 8rpx)`、白底、`border-radius:20rpx`、`box-shadow:0 2rpx 6rpx rgba(0,0,0,.05)`、`margin-bottom:16rpx`、`overflow:hidden`。
- 图片区 `width:100%`、`height` 不做统一固定，`mode="widthFix"` 形成错落；`position:relative`。
- 左上分类标签与右下点赞数：绝对定位，字号 `20rpx`、白字、背景 `rgba(0,0,0,.42)`、`border-radius:8rpx`、`padding:2rpx 10rpx`；标签 `left:12rpx;top:12rpx`，点赞 `right:12rpx;bottom:12rpx`。
- 标题：`25rpx`、`line-height:1.35`、`padding:12rpx 14rpx 4rpx`、最多两行溢出省略。
- 作者行：`display:flex; align-items:center; gap:10rpx; padding:0 14rpx 14rpx`、字号 `21rpx`、色 `#9499A0`；前置 `28rpx` 圆形占位头像（渐变 `#DDE3EA→#B9C2CC`）。

### 3.5 必须保留的既有元素

- 未登录时的「微信登录」入口（可放到头像位置或卡片区上方，样式改为 `.pa-btn-ghost`，但功能与触发条件不变）。
- 分类加载失败提示与「重试分类」、列表失败重试、加载中、暂无作品、没有更多——这 5 个状态文案与触发逻辑**一个字都不改**，只跟随新样式。
