# F8 我的页视觉与分栏执行卡

## 1. 目标与用户路径

目标：把「我的」页改成设计稿 ⑤ 屏的视觉（渐变头部 + 悬浮信息卡 + 三栏统计），并把四个入口做成**固定的一行 tab**，选中哪个就切换下方内容区滚动。

用户路径：进入「我的」→ 顶部渐变头 + 头像/昵称/简介 + 作品·收藏·获赞 三栏 → 下面一行「作品 / 收藏 / 点赞 / 设置」→ 点任一项切换下方列表，列表独立滚动、独立分页。

依据：`docs/preview/photoai_mockup.html` 第 112–125 行（`.me-hero` / `.me-card` / `.me-top` / `.stats` / `.me-list`）；`docs/接口冻结_v1.md` §1.3 #7、§1.6 #28。

## 2. 结构（单页三段式，头部固定）

```
page（height:100vh，display:flex，flex-direction:column）
├─ header-area（flex:none，固定不滚）
│  ├─ hero 渐变条（240rpx）
│  ├─ 信息卡（margin-top:-60rpx 压住 hero）
│  │  头像 104rpx（6rpx 白边，margin-top:-60rpx）｜昵称｜简介
│  │  三栏统计：作品 / 收藏 / 获赞
│  └─ 四个 tab：作品 · 收藏 · 点赞 · 设置（四等分一行）
└─ content（flex:1，scroll-view，bindscrolltolower）
   ├─ tab=works     → 状态筛选 + 作品列表
   ├─ tab=favorites → 收藏作品列表
   ├─ tab=likes     → 空态「点赞列表暂未开放」
   └─ tab=settings  → 编辑资料 + 退出登录
```

**头部必须固定**：`page` 设 `height:100vh; display:flex; flex-direction:column; overflow:hidden`，header 用 `flex:none`，内容区用 `<scroll-view class="content" scroll-y>` + `flex:1; min-height:0`。**不得用整页滚动 + `position:fixed` 头部**（会把内容遮住）。

## 3. 视觉规格（1px = 2rpx）

| 元素 | 规格 |
|---|---|
| hero | 高 `240rpx`，`linear-gradient(135deg,#FB7299,#FF9EB5 60%,#FFD1DC)` |
| 信息卡 | 白底，`border-radius:24rpx`，`margin:-60rpx 28rpx 0`，`padding:28rpx` |
| 头像 | `104rpx` 圆形，`border:6rpx solid #FFFFFF`，`margin-top:-60rpx` |
| 昵称 | `32rpx` / `700` / `var(--ink)` |
| 简介 | `24rpx` / `var(--ink-3)`，`单行省略` |
| 统计三栏 | `display:flex`，每栏 `flex:1`，`text-align:center`；数字 `32rpx`/`700`/`var(--ink)`，标签 `22rpx`/`var(--ink-3)`，栏间 `1rpx solid var(--line)` 竖分隔（用 `border-left`，首栏不加） |
| tab 行 | `display:flex`，四项各 `flex:1`，`text-align:center`，`padding:16rpx 0`，字号 `28rpx`，白底，`border-bottom:1rpx solid var(--line)` |
| tab 选中 | 文字 `var(--pink)` + `font-weight:700` + 下方 `32rpx×6rpx` 圆角短横（`::after` 绝对定位，参考 F6 的 `.gallery-tab.on::after`） |
| 作品卡 | 沿用现有卡片视觉（缩略图 + 标题 + 状态标签 + 驳回原因） |

## 4. 四个 tab 的行为

### 4.1 作品（works）
- 保留现有状态筛选：`全部 / 待审核 / 展示 / 隐藏 / 已驳回`，接口 `GET /pwork/mine?status=&page=&size=`。
- 现有 `loadWorks` / `onStatusChange` / `retryWorks` 的请求参数与分页、`noMore` 判定**原样保留**，只把滚动容器从页面换成 `scroll-view`（`onReachBottom` 改为 `bindscrolltolower`）。
- 卡片内容与状态标签、驳回原因文案不变。

### 4.2 收藏（favorites）
- 新增：`GET /favorite/mine?page=&size=` → `{list,total}`，字段与作品列表一致（`vurl/wtitle/likep` 等），图片用 `getFullUrl(item.vurl)`。
- 独立的 `favorites / favoritesPage / favoritesTotal / favoritesNoMore / favoritesLoading / favoritesError` 数据，不与作品列表共用。
- 空态：「还没有收藏的作品」。

### 4.3 点赞（likes）
- **后端没有「我赞过的」接口**，本 tab 固定显示空态文案「点赞列表暂未开放」，**不得发任何请求、不得用假数据填充**。

### 4.4 设置（settings）
- 两项：「编辑资料」→ `wx.navigateTo('/pages/userEdit/userEdit')`（现有方法 `goEditProfile` 复用）；「退出登录」→ 现有 `doLogout`。
- 退出登录需二次确认（`wx.showModal`），沿用现有逻辑。

## 5. 统计三栏的数据来源

| 栏 | 来源 | 说明 |
|---|---|---|
| 作品 | `GET /pwork/mine?page=1&size=1`（**不带 status**）的 `total` | 单独请求一次，只取总数，不并进列表分页 |
| 收藏 | `GET /favorite/mine?page=1&size=1` 的 `total` | 同上 |
| 获赞 | **无接口** | 显示 `—`（长破折号），**不得显示 0 冒充真实数据** |

统计在 `onShow` 时刷新一次。

## 6. 页面/文件清单

以下路径相对 `WeChat Mini Program/pg/`。新增文件：无。

- 修改 `pages/mine/mine.wxml`、`.wxss`、`.js`、`.json`。

## 7. 人眼验收清单

- [ ] 进入「我的」→ 顶部渐变头 + 头像压在渐变上（白边可见）+ 昵称/简介。
- [ ] 三栏统计 → 作品实数 / 收藏实数 / 获赞显示 `—`（不是 0）。
- [ ] 四个 tab → **作品/收藏/点赞/设置 四等分一行**，与首页排序行视觉一致。
- [ ] 向下滚动内容 → **头部与 tab 行完全不动**，只有下方列表滚。
- [ ] 切到「收藏」→ 列表换成收藏作品，与作品列表互不串数据（切回来页码/内容不重置成别人的）。
- [ ] 切到「点赞」→ 显示「点赞列表暂未开放」，**无请求发出**（可在 Network 面板确认）。
- [ ] 切到「设置」→ 编辑资料可跳 `userEdit`，退出登录有二次确认。
- [ ] 作品 tab 的五个状态筛选 → 行为与改造前一致。
- [ ] 列表触底 → 加载下一页；无更多时提示一次且不重复请求。
- [ ] 未登录进入 → 跳登录（沿用现有守卫），不出现接口报错原文。

## 8. 禁止行为

- **不得把获赞数伪造成 0 或估算值**；无接口就显示 `—`。
- **不得为「点赞」tab 编造接口或本地假数据**。
- **不得改动 `loadUserInfo` / `loadWorks` / `onStatusChange` / `retryWorks` / `doLogout` / `goEditProfile` 的既有请求参数与业务判定**；本轮只允许把它们迁移到新容器并新增收藏相关逻辑。
- 不得新增页面、不得改 `app.json`、不得改后端。
- 不得用整页滚动 + `position:fixed` 头部冒充"固定"（会在 iOS 上遮内容）。
- 不得删除现有的加载中/失败重试/空态/没有更多四类提示文案。
- 不得使用 `#3b82f6` `#2563eb` `#6b7280` `#f5f7fb` 旧色值；不得在 WXML 属性里写 `&amp;&amp;` / `&lt;` 等 HTML 实体。
- 不使用 git；不修改上列之外文件；未执行的验证项必须标注未验证。
