# F9 我的页统计修订与关系页执行卡

## 1. 目标

在 F8 已完成的「我的」页上修订两点，并新增一个关注/粉丝/获赞共用的关系列表页：

**头部保持 F8 现状不改** —— 渐变 hero（240rpx）+ 悬浮信息卡（头像/昵称/简介）+ 当前排版一律不动。本轮只动：统计栏的三栏内容、第三个 tab 的文案、以及新增关系页。参考抖音的是**行为模式**（点 tab 切内容、点统计数字进列表），不是布局。

1. 统计栏从 `作品 / 收藏 / 获赞` 改为 **`获赞 / 关注 / 粉丝`**，显示真实数据量，三栏均可点击跳转；
2. 四个 tab 里的 **`点赞` 改为 `喜欢`**；
3. 新增 `pages/relation/relation`，按 `type` 展示 关注 / 粉丝 / 获赞 三种列表。

依据：`docs/cards/F8_我的页视觉与分栏_执行卡.md`（已合入的视觉与分栏结构）；`docs/接口冻结_v1.md` §1.7 #31、#32。

## 2. 接口事实（已核实）

| 能力 | 接口 | 返回 |
|---|---|---|
| 关注列表 | `GET /follow/following?page&size` | `{list,total}`，每项 `uid / nickname / avatar / bio` |
| 粉丝列表 | `GET /follow/followers?page&size` | 同上 |
| 获赞列表 | **无接口** | 显示「获赞列表暂未开放」，**不得发请求、不得造假** |

统计数值的取法：`GET /follow/following?page=1&size=1` 与 `GET /follow/followers?page=1&size=1` 的 `total`；获赞栏固定渲染 `—`。

## 3. 统计栏改造（`pages/mine/*`）

- 三栏顺序固定：**获赞 / 关注 / 粉丝**。
- 每栏：数字在上（`32rpx`/`700`/`var(--ink)`），标签在下（`22rpx`/`var(--ink-3)`），栏间 `1rpx solid var(--line)` 竖分隔（首栏不加）。
- 获赞栏数字固定为 `—`（无接口，**禁止显示 0**）。
- 关注、粉丝显示接口 `total`；请求失败时显示 `—`，不得显示 0 冒充。
- **三栏均可点击**，跳转规则：
  - 获赞 → `pages/relation/relation?type=likes`
  - 关注 → `pages/relation/relation?type=following`
  - 粉丝 → `pages/relation/relation?type=followers`
- 点击时若未登录，走现有 `app.requireLogin` 守卫。
- 三栏需有可点反馈：`hover-class` 或按下 `opacity: .6`（任选一种，写明即可）。

## 4. tab 文案（`pages/mine/*`）

- `点赞` → **`喜欢`**（tab 文案、`data-tab` 值可保留 `likes` 不变，只改显示文字）。
- 该 tab 的空态文案改为「**喜欢列表暂未开放**」，仍然**零请求、零假数据**。

## 5. 新增关系页 `pages/relation/*`（4 个新文件）

- `app.json` 的 `pages` 数组**末尾追加** `"pages/relation/relation"`（只允许这一处改动）。
- `relation.json`：`navigationStyle: custom`、`enablePullDownRefresh: false`。
- 结构：
  - 自绘头部：左侧 `‹` 返回 + 居中标题（按 type 显示 关注 / 粉丝 / 获赞），状态栏高度用 `wx.getWindowInfo().statusBarHeight` 避让，白底 + 底部 `1rpx solid var(--line)`。
  - 列表：每行 `头像 80rpx 圆形 + 昵称 28rpx + bio 22rpx 灰色单行省略`，行间 `1rpx solid var(--line)`，`padding:24rpx`。
  - 触底加载下一页（`page/size=10`），`noMore` 后提示「没有更多了」。
  - states：加载中 / 加载失败重试 / 空态。
- 行为：
  - `type=following` → `GET /follow/following`
  - `type=followers` → `GET /follow/followers`
  - `type=likes` → **不发请求**，直接显示空态「获赞列表暂未开放」
  - 缺少或非法 `type` → 按 `following` 处理（不得白屏）
  - 返回：`wx.navigateBack()`，无栈时 `wx.switchTab('/pages/mine/mine')`
- 视觉：颜色一律用 `var(--ink)` / `var(--ink-3)` / `var(--line)` / `var(--card)` / `var(--bg)`，头像无图时用 `linear-gradient(135deg,#FFB3C7,#FB7299)` 占位。

## 7. 人眼验收清单

- [ ] 「我的」页统计栏 → 依次为 **获赞 / 关注 / 粉丝**，获赞显示 `—`，关注与粉丝为真实数字。
- [ ] 点「关注」→ 跳关系页，标题「关注」，列出已关注用户；返回可回到「我的」。
- [ ] 点「粉丝」→ 同上，标题「粉丝」。
- [ ] 点「获赞」→ 跳关系页但显示「获赞列表暂未开放」，**Network 面板无请求**。
- [ ] 三个 tab 点击都有按下反馈（不是点了没反应）。
- [ ] 四个 tab → 显示 **作品 / 收藏 / 喜欢 / 设置**（第三项是"喜欢"）。
- [ ] 切「喜欢」→ 显示「喜欢列表暂未开放」，零请求。
- [ ] 关系页列表触底 → 加载下一页；到底提示「没有更多了」。
- [ ] 关系页返回箭头 → 左上角小圆点，不再是拉长黑影（沿用 F7 修好的做法）。
- [ ] 未登录点统计栏 → 跳登录，不弹接口报错原文。

## 8. 禁止行为

- **不得为获赞编造数字或接口**；无数据就 `—`，点进去就说「暂未开放」。
- **不得给「喜欢」tab 发请求或填假数据**。
- 不得改动 F8 已验收的分栏结构（`100vh` + `flex` + `scroll-view` 固定头部方案）与两个列表的独立分页状态。
- **不得改动 F8 的头部视觉**：渐变 hero 高度、悬浮卡的负边距/圆角/内边距、头像尺寸与白边、昵称/简介排布一律保持现状。
- 不得改 `loadWorks` / `onStatusChange` / `loadFavorites` / `switchTab` 的既有请求参数与判定。
- `app.json` **只允许**在 `pages` 数组末尾追加 `"pages/relation/relation"`。
- 不得新增依赖、组件、字体、图标库；除关系页外不得新增页面。
- 不得在 WXML 属性里写 `&amp;&amp;` / `&lt;` 等 HTML 实体（历史编译阻塞坑）。
- 不得使用 `#3b82f6` `#2563eb` `#6b7280` `#f5f7fb` 旧色值。
- 不使用 git；不修改上列之外文件；未执行的验证项必须标注未验证。
