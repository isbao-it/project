# T-01 登录接口限流 · 冻结测试卡

## 0. 卡面契约（**钉死，不得改**）

| 项 | 值 |
|---|---|
| 受保护接口 | `POST /user/login`（form 参数 `pnum`、`pwd`） |
| 限流维度 | **客户端 IP**（`request.getRemoteAddr()`，**不信任** `X-Forwarded-For`） |
| 阈值 / 窗口 | **5 次 / 60 秒**（固定窗口），配置键 `ratelimit.login.max`、`ratelimit.login.window-seconds` |
| Redis 键 | `rl:login:{ip}`，TTL = window-seconds |
| 超限响应 | **HTTP 429**；body `{"code":429,"msg":"too_many_requests","data":null}`；响应头 `Retry-After: <剩余秒>` |
| 未超限 | 维持原业务响应（密码错 = HTTP 200 + body `code:401`，**本卡不改这个旧契约**） |
| 其他接口 | `/user/info`、`/pwork/list` **不受**该限流影响 |
| Redis 不可用 | **fail-open**：放行请求 + 记 WARN 日志；**不得**因 Redis 故障返回 5xx |

## 1. 测试目标

在**实现不存在**时先冻结验收测试：证明"登录接口按 IP 限流 5 次/60 秒，超限返回真实 HTTP 429"。
完成口径：工人在**当前基线源码**上跑出预期红灯（失败原因必须是"没有 429"，不是编译/环境错）。

## 2. A→T 映射（每条必须有 T）

| A | 要求 | T 用例 |
|---|---|---|
| A-01 | 阈值内放行 | `t01_under_limit_not_429` |
| A-02 | 第 6 次拒绝 | `t02_sixth_request_429` |
| A-03 | 拒绝可重试 | `t03_retry_after_header` |
| A-04 | 窗口过期恢复 | `t04_recovers_after_window` |
| A-05 | 只限登录接口 | `t05_other_endpoint_unaffected` |
| A-06 | 按 IP 隔离 | `t06_other_ip_unaffected` |
| A-07 | Redis 故障降级 | `t07_fail_open_when_redis_down`（P2，可标 @Disabled 并写理由） |

## 3. 用例与精确断言

| 用例 | 输入 | 精确断言 |
|---|---|---|
| `t01` | 同一 IP 连发 5 次错密码登录 | 5 次的 status **≠ 429**；且 body `code == 401` |
| `t02` | 第 6 次同 IP | status **== 429**；body `code == 429`；`msg == "too_many_requests"` |
| `t03` | 同 `t02` 的响应 | header `Retry-After` 存在，且整数 **1 ≤ v ≤ 60** |
| `t04` | 用 `ratelimit.login.window-seconds=2` 起上下文；打满 5 次→429；睡 2.5s；再打 1 次 | 最后这次 **≠ 429** |
| `t05` | 同一 IP 对 `/user/info` 连发 6 次（无 token） | 6 次 status **≠ 429**（允许 401） |
| `t06` | IP `10.0.0.1` 打满 6 次（第 6 次 429）；换 IP `10.0.0.2` 打 1 次 | `10.0.0.2` 的这次 **≠ 429** |
| `t07` | 指到不存在的 Redis 端口（`spring.redis.port=6390`）后请求 1 次 | status **≠ 5xx**；且日志/响应体现已放行 |

> 断言用 **HTTP 状态码 + body 的 `code`/`msg`**，**禁止**断言中文文案、禁止断言耗时。

## 4. 实现方式（不自由发挥）

- `@SpringBootTest` + `@AutoConfigureMockMvc`（MockMvc 会经过拦截器，且能改 `remoteAddr`）。
- 换 IP：`mockMvc.perform(post("/user/login").with(req -> { req.setRemoteAddr("10.0.0.1"); return req; })...)`。
- Redis 用**真实例**（`redis-server` 或 `docker run -d -p 6379:6379 redis:7-alpine`），**禁止**用内存假实现替代。
- 登录请求用不存在的手机号（如 `13800000000`）+ 任意密码，**不依赖种子账号密码**。
- `t04` 用 `@SpringBootTest(properties = {"ratelimit.login.window-seconds=2"})` 单独测试类，避免和其他用例互相污染；**每个用例前清空 `rl:login:*` 键**（用 Redis 客户端 `SCAN`+`DEL`，或换一个随机前缀 IP）。
- 测试类放 `src/test/java/com/pg/ratelimit/RateLimitTest.java`；如需基类/工具放同包。
