## §8 对流水线的直接结论

1. **不能按"技术清单"出卡**——清单是目标态，照它出卡会让工人实现一堆不存在的前提。
2. **出卡顺序建议**：先补"基线三件"（权限矩阵 / schema 与 E-R 说明 / 错误码枚举）→ 再补三个空壳模块 → 再做 AI 检索 → 最后部署与演示。
3. **E1 的冻结测试**从"用户登录 / 作品列表 / 作品详情 / 投票"这 4 个已可用模块开始，否则没有可冻结的测试对象。
