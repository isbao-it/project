# 论文要求速查（PhotoAI Hub）

> **只认一份硬性来源**：《广东培正学院毕业论文（设计）指南（2027届）》（通用版）。
> 其余三份是参考：`开题报告样例`（只管开题怎么写）、`毕业论文样例`（只示范章节长什么样）、`选题忌讳.docx`（网络经验文，**不是校规**，不能引用当依据）。

## 一、硬门槛（不过就进不了答辩）

| 项 | 要求 | 依据 |
|---|---|---|
| 查重 | **相似比 ≥30% 不得进入答辩**；评"优秀"需 **≤10%** | 第十三条（三）1（7）· 第十六条（三）3 |
| 字数 | **毕业设计（说明书）≥6000 字**；毕业论文 ≥8000 字 | §3 正文的规范 |
| 摘要 | 中文 250–300 字，外文正常翻译 | §2 |
| 关键词 | 3–5 个，分号隔开 | §2 |
| 参考文献 | **≥10 篇**；**近 3 年 ≥1/3**；**外文 ≥1/5**（不含译文）；学位论文 ≤1/5 | §3.4 |
| 目录 | 按三级标题，独立成页，标题与正文一致 | §1 |
| 图表 | **三线表**；图题在图**下方**，表题在表**上方**，先文后图 | §4.1 / §4.2 |
| 成绩 | 指导 **50%** + 评阅 **20%** + 答辩 **30%**；A≥90 / B≥80 / C≥60 | 第十三条（四） |
| 答辩 | 自述 + 提问（**每生不少于 3 问**），**每生 ≥20 分钟** | 第十三条（三）2 |
| 原创性 | 原创性声明 + 版权授权书，手写签名 | 模板 |

> 题目是"设计与实现"→ 走**毕业设计（说明书）**，**6000 字**够线，不是 8000。

## 二、开题阶段（单独的规则）

- 文献综述 **2000 字左右**，按论文格式打印在第一栏。
- 开题参考文献 **≥10 篇**，顺序编码制（GB/T 7714）。
- 日期一律阿拉伯数字（`2027-05-12`）。
- 文献综述四段式：选题目的和意义 / 国内外研究现状（可分国外、国内）/ 发展趋势 / 对本人课题的启发。

## 三、流程与表格（时间线，缺表就过不了流程）

选题审批表 → 任务书 → 选题汇总表 → **开题报告** → 中期检查记录表 → 指导情况记录表 → 指导教师评分表 → 评阅教师评分表 → 答辩记录表 → 答辩评分表 → 成绩评定表 →（如评优）推荐表。

> 中期检查会问："与开题相比内容有无调整"——**改了范围要留记录**（对应流水线的"确认记录"）。

## 四、每章需要什么证据（这决定了系统要产出什么）

| 章节 | 论文里要写 | 系统必须提供 |
|---|---|---|
| 1 绪论 | 背景、国内外现状、研究内容与目标 | 与同选题的**差异点**说明（跨模态检索 / 拍摄方案复刻 / AI 可关闭） |
| 2 相关技术与理论 | Spring Boot、小程序、数据库、向量检索 | **选型对比**（≥3 方案 + 淘汰理由），解释为何用旧版本 |
| 3 系统分析 | 可行性、角色需求、角色功能 | **角色—权限矩阵**（谁能调哪个接口） |
| 4 系统设计 | 架构、功能流程、E-R、数据表 | **E-R 图 + 数据表设计表**（9 表 + 6 视图 + 触发器说明） |
| 5 系统实现 | 逐模块截图 + 流程 + 关键代码 | 可演示的模块（含 AI 模块） |
| 6 系统测试 | 测试方法、功能测试表、测试分析 | **真实用例 + 通过/失败 + 时延/命中率数据** |
| 7 总结与展望 | 成果、不足、后续 | 未验证项清单（诚实写，比吹牛安全） |

## 五、对本项目的 6 条硬约束（出卡前逐条勾）

- [ ] **文档与系统一致**：清单里承诺的 CLIP / NIMA / Redis / Docker / 内容审核，代码里有没有？没有就"补齐 / 论文降级 / 删掉"，三选一，落成记录。
- [ ] **创新点可验证**：关键词检索 vs 向量检索的 **Top-5 命中率 + P95 时延**，一张对比表（第 6 章要用）。
- [ ] **测试真跑**：第 6 章要用例表，现在只有 1 个空上下文测试 → 必须补真实测试（E1 冻结测试正好产出）。
- [ ] **隐私合规**：上传即剥离 EXIF 的 GPS / 设备序列号，并在论文写合规说明。
- [ ] **可离线演示**：一键启动（compose 或脚本）+ 演示视频 + 备用录屏；不能"换台电脑就挂"。
- [ ] **查重安全**：不抄样例段落（样例标"内部资料勿外传"）；技术清单是目标态，**不能直接当论文正文**。

## 六、常被误当"要求"的项（别自己吓自己）

| 说法 | 实际情况 |
|---|---|
| "参考文献必须 10 篇以上"（开题+论文各算） | 开题和论文**各自**≥10，不是合计 |
| "论文 8000 字" | 那是**论文**；你是**设计说明书**，≥6000 |
| "第 6 章必须有 6 张测试表" | 那是样例学生的写法，**不是硬性**；硬性只有"有真实测试与结果" |
| "选题忌讳 20 条是校规" | 网络经验文，参考性质；校规只有《指南》 |
| "查重 ≤10%" | 那是**评优秀**的门槛；及格线是 **<30%** |
