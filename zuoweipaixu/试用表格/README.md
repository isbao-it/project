# 试用表格（全部为虚构姓名）

配套应用：同目录上一级的 `index.html`（双击，断网可用）。

| 文件 | 怎么用 | 预期结果 |
| --- | --- | --- |
| 00_快速试用_8人_4x2应全满.xlsx | 排数 4、每排座位数 2 | 8 格全满、无空位 |
| 01_两列_48人_6x8应全满.xlsx | 选「第 2 列」，6×8 | 48 格全满、无空位、无未分配 |
| 02_两列_24人_6x8前三排满后三排空.xlsx | 同上 | 前三排坐满，后三排整排显示「空」 |
| 03_两列_50人_6x8应有2人未分配.xlsx | 同上 | 48 人入座 + 提示「有 2 人未分配」 |
| 04_三列_需选第3列.xlsx | 下拉会出现第 1/2/3 列 | 选「第 3 列」才拿到姓名；选第 1 列（学号）会导错 |
| 05_单列_无表头_20人.csv | 直接选列确认 | 20 人入座 |
| 06_单列_带表头_24人.csv | 直接选列确认 | 表头「姓名」被跳过，24 人 |
| 07_空表_只有表头_应提示未读取到.xlsx | 上传后确认一列 | 提示「未读取到学生名单」，且表格仍保留可重选 |
| 08_坏文件_文本改名xlsx.xlsx | 上传 | 提示「文件格式不正确或已损坏」 |
| 09_特殊姓名_转义与安全.xlsx | 选「第 2 列」，4×2 | 复制出的 Markdown 里 \|、&、< 被转义；页面上不出现粗体/图片；「空」是名字不是空位；重复姓名保留；首尾空格被去掉 |
| 10_大名单_500人.xlsx | 选「第 2 列」，25×20 | 秒出（实测约 15 毫秒） |
| 11_无表头xlsx_27人.xlsx | 5×6 | 27 人入座，末排余 3 个「空」 |

复现同一次结果：三处输入（名单文件、行列、种子）保持一致即可；种子留空会自动生成并回填到输入框。
